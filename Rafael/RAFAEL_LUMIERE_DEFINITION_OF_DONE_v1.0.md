RAFAEL / LUMIERE — DEFINITION OF DONE v1.0


Назначение
Этот документ определяет, когда работа Рафаэля в режиме LUMIERE по конкретной сцене считается полностью завершенной и keyframe можно вернуть Люмьеру.


1. ОБЯЗАТЕЛЬНЫЙ СТАТУС
Финальный статус сцены: APPROVED.
Никакой DRAFT, REGENERATE или PARTIAL не может считаться завершением.


2. VISUAL DNA — PASS
Keyframe обязан соответствовать Visual DNA сцены:
- правильный сезон;
- правильное настроение;
- правильный свет;
- согласованная цветовая среда;
- нужные визуальные акценты;
- отсутствуют запрещенные визуальные признаки.


3. SCENE INTENT — PASS
Кадр должен ясно передавать SCENE_MESSAGE и выполнять SCENE_ROLE.
Главный объект или действие считываются без дополнительных пояснений.


4. MANDATORY / FORBIDDEN — PASS
Все элементы из MANDATORY присутствуют.
Все элементы из FORBIDDEN отсутствуют.


5. FORMAT — PASS
- вертикальный формат 9:16;
- один цельный кадр;
- фотореализм;
- без коллажа;
- без постерной верстки;
- без текста, цены, дат и логотипов;
- достаточная резкость исходного изображения.


6. SAFE ZONES — PASS
Лицо Симбы, глаза, главный продукт и незаменимые детали не попадают в опасные зоны интерфейса Reels.
Композиция сохраняет смысл при небольшом crop.
Зона под будущие титры остается визуально пригодной.


7. SIMBA IDENTITY — PASS
Если в сцене есть герои, один из них обязательно Симба.
Если Симба присутствует:
- используется текущая ACTIVE_VERSION официального SIMBA MASTER REFERENCE;
- сохраняются лицо, форма морды, грива, цвет шерсти, возраст, телосложение и пропорции;
- Симба остается фотореалистичным антропоморфным львом;
- не допускается подмена другим львиным персонажем или возврат к обычному четвероногому льву.


8. SIMBA CONTINUITY — PASS
Если Симба уже появлялся в этом Reel:
- identity совпадает с предыдущими APPROVED keyframe;
- сохраняется одна и та же master-version;
- отсутствует заметный визуальный дрейф персонажа.


9. OUTFIT CONTINUITY — PASS
Если для данного Reel уже зафиксирован OUTFIT ANCHOR:
- сохраняются одежда, основные цвета, крой и ключевые детали;
- аксессуары сохраняются, если нет сюжетной причины их изменить;
- любая смена образа должна иметь явный OUTFIT_CHANGE_REASON от Люмьера.


10. CHARACTER ANATOMY — PASS
У Симбы и других героев нет заметных дефектов:
- лица и морды;
- глаз;
- рук, кистей, лап;
- тела и пропорций;
- случайных слияний персонажей с предметами или друг с другом.


11. COMPOSITION — PASS
- есть понятный визуальный центр;
- главный объект легко считывается;
- композиция естественно работает в 9:16;
- желательно есть передний, средний и задний планы;
- кадр не перегружен второстепенными деталями.


12. A2E_SAFE — PASS
Keyframe пригоден для последующей анимации:
- нет motion blur;
- нет заведомо нестабильной геометрии;
- есть естественный потенциал движения;
- нет чрезмерно сложных отражений, толп, мелкой типографики и других высокорисковых деталей;
- ключевые объекты имеют четкие границы;
- вероятность серьезных артефактов оценивается как приемлемая.


13. TECHNICAL CLEANLINESS — PASS
На изображении нет:
- случайного текста;
- водяных знаков;
- чужих логотипов;
- артефактов генерации;
- лишних пальцев, конечностей или объектов;
- визуальных ошибок, заметных при обычном просмотре.


14. FILE IDENTITY — PASS
У результата есть стабильное имя по шаблону:
<REEL_ID>__SCENE_<NN>__KF__APPROVED__v<NN>


APPROVED-версия не перезаписывается.
Новая генерация всегда получает новый номер версии.


15. QC SUMMARY
Перед возвратом Люмьеру Рафаэль формирует итоговый блок:


SCENE_ID: <id>
STATUS: APPROVED
KEYFRAME: <image>
MASTER_VERSION: <SIMBA_MASTER_vX.X или N/A>
OUTFIT_ANCHOR: <id / description / N/A>
QC:
- Visual DNA: PASS
- Scene intent: PASS
- Mandatory / Forbidden: PASS
- Format: PASS
- Safe zones: PASS
- Simba identity: PASS / N/A
- Simba continuity: PASS / N/A
- Outfit continuity: PASS / N/A
- Character anatomy: PASS / N/A
- Composition: PASS
- A2E safe: PASS
- Technical cleanliness: PASS


16. FAILURE RULE
Если хотя бы один обязательный критерий = FAIL, keyframe не может получить STATUS: APPROVED.
Рафаэль обязан:
- либо перегенерировать сцену в рамках допустимого числа попыток;
- либо вернуть ее Люмьеру с FAIL_CODE, REASON и ACTION.


17. DEFINITION OF DONE
Сцена считается DONE только тогда, когда все применимые проверки имеют PASS, файл корректно именован, а финальный статус равен APPROVED.


После этого Рафаэль возвращает approved keyframe Люмьеру. Сам Рафаэль не передает изображение в A2E и не управляет дальнейшей анимацией.
