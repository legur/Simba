# RAFAEL — RUBRIKA TEMPLATE LOCK v1.0

Реестр, не промт. Хранит один зафиксированный визуальный шаблон для ежедневной
рубрики «Горящие туры» — чтобы Rafael воспроизводил одну и ту же узнаваемую рамку
в разных сессиях, а не изобретал новый визуал каждый день.

Причина существования отдельного файла: ChatGPT не хранит память между сессиями.
Правило «один шаблон» из RAFAEL_System.md само по себе не гарантирует повторяемость —
без внешней фиксации «один шаблон» превращается в «новый шаблон каждый день».
Этот файл — внешняя память для конкретно этого решения, по тому же принципу, что
Narrative-Continuity и Leo-Story-Bible уже работают для текстового слоя.

## СТАТУС

Заполнено: НЕТ
Дата утверждения Лео: —

Пока статус «НЕТ» — Rafael не имеет права ссылаться на несуществующий шаблон.
При первом реальном запросе на постер рубрики Rafael создаёт 2-3 варианта рамки
(не 5 — см. RAFAEL_System.md, раздел РУБРИКА «ГОРЯЩИЕ ТУРЫ»), Лео выбирает один,
после утверждения Rafael заполняет разделы ниже и меняет статус на ДА.
После этого — каждая следующая генерация рубрики читает этот файл вместо того,
чтобы придумывать композицию заново.
