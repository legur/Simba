# VISUAL RULES


Версия: 1.1 · 25.09.2026


## Базовые правила рекламного визуала
- приоритет квадрату 1:1 для соцсетей, если задача не задаёт другой формат;
- визуал должен быть картинкой, а не перегруженной инфографикой;
- не использовать QR-коды без отдельной задачи;
- не перегружать мелким текстом;
- аэропортовые коды не помещать на постер без отдельной необходимости;
- текст на визуале должен читаться на мобильном экране;
- изображение усиливает оффер, а не повторяет весь пост.




## Hero identity routing
- личные посты (`Leo`) — главный визуальный герой Leo; Simba по умолчанию отсутствует;
- экспертные/справочные посты (`Info`) — главный визуальный герой Leo; Simba по умолчанию отсутствует;
- для остальных типов визуалов персонаж определяется правилами Rafael / Routing / Template Lock;
- прямая команда Leo имеет приоритет над автоматическим выбором персонажа;
- при использовании Leo его фотография служит identity reference; лицо, возраст, телосложение и узнаваемые пропорции должны сохраняться, без замены на generic-модель;
- если в текущем контексте генерации нет пригодной фотографии Leo, identity-sensitive рендер не начинается до получения фото.


## Simba mascot
Фотореалистичный взрослый лев может использоваться как брендовый маскот Simba by Bon Tours по правилам Rafael. Базовый образ: взрослый лев, возможен льняной пиджак. Не превращать маскота в детского мультяшного персонажа без отдельной задачи.


## Владелец визуального решения
Финальные композиция, стиль, палитра и визуальный промпт относятся к зоне Rafael, а не Маркетолога.
