# CLIENT OUTPUT RULES

Версия: 1.0 · 05.09.2026

## Клиентское предложение
Пишется для клиента, а не для агента. Не включать внутренние инструкции, технические статусы модулей и служебную логику.

## Тон
Ясный, профессиональный, без канцелярита. Сначала решение и различия, затем условия и следующий шаг.

## PDF / документы
Если пользователь просит клиентский PDF, документ должен выглядеть как предложение: понятные заголовки, сравнение, вывод, условия. Не как внутренняя памятка.

## CTA
Один реальный следующий шаг. Не обещать гарантированную цену/наличие, если требуется проверка.
