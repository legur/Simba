# SOURCE PRIORITY

Версия: 1.0 · 05.09.2026

## Типы знаний
### Постоянные
Стиль, бренд, аудитория, бизнес-правила, процессы и ограничения. Их можно хранить и переиспользовать.

### Динамические
Цена, наличие, расписание, тариф, акция, срок, правила въезда, условия отмены, включения и текущий статус предложения.

## Главное правило
Сохранённое динамическое значение не становится текущей истиной только потому, что находится в базе знаний.

Если Маркетолог получил факты от конкретного рабочего источника для текущей задачи, он принимает их как рабочую истину на указанную дату актуальности, нормализует и передаёт исполнителю. Он не обязан самостоятельно перепроверять их во внешних системах, если это отдельно не требуется процессом.

## Приоритет источников для исследования
1. официальный поставщик / авиакомпания / круизная линия / отель / госорган;
2. договорные или агентские системы;
3. профильные профессиональные источники;
4. агрегаторы и вторичные публикации;
5. форумы и соцсети — только как мнение/сигнал, не как источник тарифного факта.
