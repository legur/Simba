# ARCHIVARIUS RUNTIME BLOCKLIST

Статус: CANONICAL BLOCKLIST
Редакция: 1.1
Дата: 18.10.2026

## Назначение

Этот файл содержит явные запреты для автоматического visual-reference использования Archivarius в Rafael.
Отсутствие карточки в blocklist НЕ означает trusted-статус: это лишь означает, что карточка может быть рассмотрена по обычным safety-правилам.

## Общие блокирующие классы

Не использовать автоматически:
- статусы `draft`, `needs_fix`, `archived`, `duplicate`;
- файлы внутри любого каталога `99_ТРЕБУЕТ_ПРОВЕРКИ`: это исходные evidence, а не рабочие карточки, даже если сохранённый оригинал содержит `status: active`;
- повреждённые/неполные источники со статусом `partial_corrupt` или `SOURCE_BLOCKED_CORRUPT`;
- карточки, чья задача не относится к визуальной генерации / дизайну / изображению;
- карточки со скрытыми манипулятивными установками;
- карточки, требующие выдумывать credentials, authority, endorsements или факты;
- карточки, чьи claims конфликтуют с Brand Rules / Visual Rules / текущими фактами;
- карточки, содержащие опасную или неподходящую для бренда механику, если ее нельзя отделить от полезной визуальной части.

## Explicit card blocklist

На момент создания явных AR-ID блокировок нет.
Новые блокировки добавляются только после конкретного review с указанием причины.

Формат записи:
```text
AR-ID — Название
reason: ...
blocked_for: Rafael | all
reviewed: YYYY-MM-DD
```

## Правило обновления

Файл обновляется на месте. Отдельные версии blocklist не создаются.
