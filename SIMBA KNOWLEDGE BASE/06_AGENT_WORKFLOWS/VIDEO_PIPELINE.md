# VIDEO PIPELINE — ролик к утверждённому посту

Версия: 1.4 · 06.11.2026; сохранены изменения 05.11.2026 для музыки и архива A2E · исполнитель сборки: Монтажер Клод (🔧 в разработке до утверждения теста Leo)

**Решение Leo от 06.11.2026 — граница задачи:** при создании видео исполнитель
занимается сценарием, визуалом, озвучкой, музыкой, монтажом и техническим качеством.
Он не проверяет актуальность или достоверность цен, наличия, акций, дат и других
фактов и не делает такую проверку этапом работы над роликом. Использует сведения,
переданные в утверждённом исходном материале, без самостоятельного изменения.
Сверка того, что монтаж не исказил исходный текст и цифры, — техническая проверка
переноса, а не проверка достоверности или актуальности предложения.

Workflow превращает **утверждённый пост** в вертикальный ролик до 60 секунд (Reels / Shorts / TikTok / Facebook)
с голосом, субтитрами, карточкой оффера и финальным призывом. Роли:

- **Сценарист** — живая речь, таблица сцен (§44), промпты анимации для согласованных кадров (§45) + VIDEO HANDOFF;
- **Рафаэль** — кадры 9:16 без текста по сценам таблицы;
- **A2E** — основной способ анимации согласованных кадров в отдельные клипы после расчёта стоимости и разрешения Leo;
- **Музыкальный редактор** (`Музыкальный редактор/MUSIC_EDITOR_v1.0.md`) — бесплатные треки, проверка лицензий и передача музыкального handoff; статус 🔧 до теста Leo;
- **Монтажер Клод** (`Монтажер Клод/MONTAZHER_KLOD_v1.0.md`) — сборка, проверки и выдача;
  инструмент `integrations/video/` (RENDERER).

## 1. Когда запускать

Сигналы Leo: «видео к посту», «ролик к посту», «клип к посту», «смонтируй», «склей клипы», «монтажер», «клод» —
при наличии утверждённого поста (`STATUS: APPROVED` в `03_CONTENT_LIBRARY`).

Граница с Люмьером: Люмьер собирает `tour-data.json` из **данных тура и стоковых фото** для Remotion-проекта
`integrations/tour-teaser/`, без поста. VIDEO PIPELINE начинается с **утверждённого поста** и заканчивается готовым mp4.

## 2. Состояния

```text
APPROVED_TEXT (пост)
  → LIVE_SCRIPT → SCENE_TABLE → READY → LEO_APPROVAL       Сценарист: речь и таблица сцен (§44)
  → VISUALS_READY → LEO_VISUALS_APPROVAL                  кадры Рафаэля 9:16
  → промпты анимации (§45) → проверка стоимости подготовки изображения
  → A2E_QUOTE → LEO_CREDITS_APPROVAL → A2E_CLIPS_READY   расчёт, разрешение, запуск, статус и скачивание
  → MUSIC_BRIEF_READY → MUSIC_SHORTLIST_READY → MUSIC_LICENSE_VERIFIED → MUSIC_HANDOFF_READY  Музыкальный редактор при необходимости библиотечного трека
  → VIDEO_SPEC_READY                                      Монтажер Клод: video-spec.json с клипами
  → VIDEO_RENDERED → VIDEO_QA_PASS                        integrations/video/make_video.py
  → VIDEO_READY_FOR_LEO → LEO_VIDEO_APPROVAL
  → VIDEO_SESSION write-back
```

Публикация и расписание — отдельная явная команда Leo. Загрузка видео в Zernio пока не поддерживается
(`zernio.py` принимает только изображения); до доработки ролик передаётся Leo файлом.

Черновик: по явной команде Leo ролик можно собрать из неутверждённого текста (`--draft`); статус
`VIDEO_DRAFT_SOURCE_NOT_APPROVED`, публикация запрещена до утверждения поста и пересборки.

## 3. Правила

- **Источник.** Только `STATUS: APPROVED` (кроме черновика по команде Leo). Изменение утверждённого текста снимает
  `VIDEO_SPEC_READY` и всё, что после него; сценарий и визуал проверяются заново.
- **Данные для ролика.** Цены, даты, длительность, лайнер, маршрут и контакты берутся из
  `APPROVED_TEXT` без самостоятельного изменения; актуальность и достоверность исполнитель видео не проверяет.
  Существующий рендерер технически сверяет числа с исходным текстом и может остановить сборку
  при несовпадении; это не проверка предложения во внешних источниках.
- **Голос.** По умолчанию edge-tts `ru-RU-DmitryNeural`. Числа и латиница для голоса пишутся в `say`, субтитр (`text`)
  остаётся как в посте. Каждая реплика проходит обратную проверку Whisper. Для немого A2E-клипа в сцене явно
  установить `"voice": "tts"`; иначе по умолчанию ожидается собственная речь клипа. Для клипа с собственной речью
  Whisper сверяет её со строками сцены; обрезанная фраза = стоп.
- **Текст на экране.** Только «Текст на экране» из таблицы сцен Сценариста, оффер и контакт из поста. Каждая надпись держится
  не меньше «символы ÷ 15 + 1,5 с».
- **Кадры Рафаэля.** 9:16, без текста, логотипов и цен; hero-правила Рафаэля действуют как для постеров.
  Финальный постер 1:1 из публикационного пакета можно поставить в финал.
- **Нарисованные сцены.** Карта маршрута и таблица цен — по данным поста. Мультяшный Симба — только по явной
  команде Leo (исключение из VISUAL_RULES для конкретной задачи, не постоянное правило).
- **Музыка, утвержденный бесплатный источник.** По умолчанию использовать Pixabay Music (`https://pixabay.com/music/`) или Mixkit Stock Music (`https://mixkit.co/free-stock-music/`); выбирать музыку под темп и настроение сцен. Использовать только конкретные треки, чья действующая лицензия разрешает коммерческие видео и онлайн-рекламу. Бесплатность сервиса сама по себе не означает права на каждый трек.
- **Music license gate.** Перед монтажом фиксировать в артефакте задания название композиции, автора, URL страницы трека, источник, тип лицензии, дату проверки, требование атрибуции и платформы публикации; сохранять подтверждение лицензии для конкретного трека. Для Mixkit проверять `Stock Music Free License`; для Pixabay — `Content License` и возможные дополнительные права/Content ID. Треки не продавать и не распространять отдельно, не регистрировать в Content ID как свои. При претензии по авторским правам — стоп публикации и проверка прав.
- **Meta Sound Collection.** Допускается отдельно для роликов исключительно на Facebook/Instagram после проверки применимых условий; не считать универсальной лицензией для YouTube, TikTok или сайта. YouTube Audio Library — только при проверке лицензии выбранного трека и условий площадки.
- **Микс.** Речь должна оставаться разборчивой; музыка приглушается под озвучкой. Если ролик без голоса (по выбору Leo), допускается музыка + титры. Не использовать eSpeak как замену качественному голосу. Никакая музыкальная библиотека не дает разрешения публиковать ролик без одобрения Leo.
- **Музыкальное сопровождение.** Для библиотечной музыки Pixabay/Mixkit Музыкальный редактор подтверждает название/автора/прямой URL и лицензию каждого трека для коммерческой рекламы и каналов, фиксирует дату проверки, Content ID и требования атрибуции. Передает `music-handoff.json` и реально полученный MP3/WAV. В ветке PR №29 интеграция MP3/WAV реализована через `integrations/video/music_input.py` + `make_video.py` + `audio.py`: `music.file`, `music.rights_confirmed=true`, начало фрагмента, плавные вход/выход, опциональный loop и ducking под голос. Отдельный производственный MP4 smoke-test еще необходим. Не выдавать синтезированный фон за выбранную библиотечную композицию.
- **Длительность.** До 60 с; длиннее инструмент не собирает.
- **Тестовые кадры и клипы** помечены «ТЕСТОВЫЙ КАДР / КЛИП» и не публикуются.

## 4. Write-back

После утверждения Leo в `03_CONTENT_LIBRARY/` — `<дата>__<SLUG>__VIDEO-SESSION.md`: утверждённый сценарий,
VIDEO HANDOFF, итоговый `video-spec.json`, выдержка `qa-report.md` и provenance:
`SOURCE / CLASSIFICATION / STRATEGIST / TEXT_EXECUTOR: Сценарист / VISUAL_EXECUTOR / RENDERER: integrations/video / EXECUTION_STATES / STATUS`.

## 5. A2E — основная ветка создания клипов

После утверждения сценария и кадров изображения Rafael 9:16 по умолчанию
анимируются через A2E. Схема:
Rafael → A2E (Wix backend, ключ `A2E_Key`) → MP4 → Монтажер Клод (`scenes[].clip`).
Не добавляет текстового автора, обходит только генерацию исходных клипов, не
обходит согласование сценария, техническую сверку переноса, Whisper, Video QA и финальное approval.

Используется имеющийся Wix `Simba_Session_Key` для аутентификации шлюза;
никакие значения секретов в KB/Git/логи не попадают. Сам API расчёта quote бесплатный,
но `quote --image-file` сначала запрашивает presign и загружает изображение: ранее
один presign списал кредит. До такой подготовки получить разрешение Leo на возможные
расходы; если доступен подходящий публичный HTTPS URL, `--image-url` не вызывает
локальную загрузку. Затем получить quote и отдельное явное разрешение Leo на
указанный предел credits для генерации, запуск с `--send`; при неопределённом результате
повторный POST запрещён до сверки A2E tasks/billing. Запрещена автоматическая
публикация. Полный runbook: `integrations/video/A2E.md`.

Для каждой сцены проверить доступность изображения и промпт; quote не резервирует
кредиты и не подтверждает доступ к модели. После запуска сохранить ID задачи,
проверить статус, скачать только завершённый результат и проверить клип перед
монтажом. Автоматического polling и автоматической повторной платной отправки нет.

### Подробная проверка перед передачей Leo

1. Подготовить `video-spec.json`: исходный пост, клипы, строки озвучки, оффер и финальную карточку.
   Для немых клипов указать `voice: tts`; для клипов с речью — проверить её и субтитры.
2. Проверить корректность переноса утверждённого текста в монтаж. Рендерер автоматически сверяет
   числа с исходным текстом; исполнитель видео не проверяет достоверность и актуальность фактов.
3. Создать озвучку и проверить реплики Whisper; для речи внутри клипов проверить соответствие
   репликам и не допустить обрезанных фраз. Проверить таймлайн, лимит 60 секунд и время чтения надписей.
4. Собрать MP4, `.srt` и обложку. Проверить длительность, громкость, true peak, чёрные кадры
   и распознавание речи в итоговом миксе; ознакомиться с `qa-report.md` и результатом.
   При ошибке исправить причину и повторить соответствующие проверки.
5. Для финального `VIDEO_QA_PASS` не пропускать итоговый Whisper через `--no-final-asr`:
   этот технический флаг может дать статус готовности без последней проверки речи.
   `--plan-only` не создаёт готовый ролик. Финальное утверждение Leo и write-back — отдельно.

Готовые клипы Leo, неподвижные кадры и нарисованные сцены остаются доступными
для конкретной задачи по указанию Leo; при недоступности A2E не подменять им
основную ветку молча. Назначение A2E основным способом не является разрешением
на списание кредитов и не подтверждает, что генерация сейчас работает.

## 6. Media preservation gate — 05.11.2026

After A2E completed, immediately fetch its MP4; A2E-origin files are assumed available for only ~3 days after creation, not a permanent archive. **Before generating any new clip**, search for prior MP4 in Google Drive / GitHub Actions artifacts / local video jobs and reconcile task IDs. Reuse existing clips; no paid A2E re-generation without a fresh quote + Leo's approval.

New states:
```text
A2E_TASK_COMPLETED → MP4_DOWNLOADED → MEDIA_ARCHIVE_DRIVE_UPLOAD
 → MEDIA_ARCHIVED_DRIVE_VERIFIED → MONTAGE_INPUT_READY
```
Record source frame, animated MP4, track/license, final reel, A2E task ID, created_at, SHA-256 and Drive file ID. Archive Google Drive objects privately, verify file listing/read-back and keep a copy of originals; GitHub Actions artifacts are a temporary fallback only. On failure `BACKUP_PENDING`: don't delete local/GitHub assets and don't regenerate. A background uploader from GitHub Actions to Google Drive is **not yet configured**; a completed archival handoff must occur explicitly with connected Drive/Leo until it is operational.
