# CONTENT PATTERN TRACKER

Версия: 2.0 · 05.09.2026  
Источник: 3 полных поста + 44 `CONFIRMED_MISSING` + исторические реакции Leo/Critic.  
`REQUESTED_OR_UNCERTAIN` исключены из анализа.

## Назначение

Не запрещать удачные авторские приёмы, а отслеживать, когда они превращаются в автоматический шаблон.

## P-001 — Анафорические серии

Пример механики: несколько соседних фраз с одинаковым началом.  
Статус: WATCH.  
Причина: приём повторялся в нескольких публикациях/сериях.

Правило: не использовать в следующем посте автоматически, если недавно уже была анафора.

## P-002 — Стаккато и однострочные абзацы

Статус: WATCH.  
Сильный приём для мобильного чтения, но при частом использовании делает разные тексты похожими друг на друга.

Правило: варьировать длину предложений и абзацев.

## P-003 — Формальный вопрос после законченного вывода

Пример механики: декларативная точка → «А вы?».  
Статус: AVOID BY DEFAULT.

Исторический сигнал: Critic отдельно отмечал слабость такого финала в посте Wizz Air.

Правило: вопрос оставлять только если он содержательно продолжает тему.

## P-004 — Цепочка «Потом...»

Статус: WATCH.

Исторический сигнал: повтор нескольких «Потом...» был отмечен как новая ритмическая однообразность после исправления другого анафорического блока.

Правило: если нужна последовательность действий, часть шагов объединять синтаксически или менять ритм.

## P-005 — Table-surrogate

Механика: каждый пункт сравнения идёт в одном порядке полей.  
Статус: AVOID IN PROSE.

Замечен в:
- сравнении Viking / Avalon / AmaWaterways / Uniworld / Scenic;
- маршрутах Virgin Voyages.

Правило: либо настоящая таблица, либо различная повествовательная логика для пунктов.

## P-006 — Один и тот же каркас в серии

Статус: WATCH.

Правило для последовательных публикаций: следующий пост должен менять минимум две оси:
1. хук;
2. структура;
3. ритм;
4. главный аргумент;
5. CTA.

## P-007 — Декларация компетентности

Механика: «надёжность/сервис/забота» заявляются напрямую без действия.  
Статус: AVOID.

Предпочтение: mechanism over declaration.

## P-008 — Сухой экспертный конспект

Статус: AVOID.

Исторический прямой сигнал Leo: «Очень сухо получилось. Сделай в стиле Лео».

Правило: экспертный материал должен иметь авторский угол, сцену, конфликт выбора или практический механизм.

## P-009 — Пафосный рекламный заход

Статус: AVOID.

Исторический сигнал: вариант по Филиппинам принят только после требования убрать пафос.

## P-010 — Отсутствие CTA в коммерческом гибриде

Статус: ERROR WHEN SALES-INTENT.

Исторически отмечено в постах Virgin Voyages и круизе солнечного затмения.

Правило: если коммерческая цель подтверждена, должен быть один понятный следующий шаг.

## Перед новым постом

Сравнить с последними материалами по пяти осям:
1. хук;
2. структура;
3. ритм;
4. главный аргумент;
5. CTA.

Паттерн сам по себе не является ошибкой. Ошибка — бессознательная повторяемость без содержательной причины.
