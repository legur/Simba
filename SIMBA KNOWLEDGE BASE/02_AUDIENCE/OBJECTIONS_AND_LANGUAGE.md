# OBJECTIONS AND CLIENT LANGUAGE

Версия: 1.0 · 05.09.2026

## Типовые вопросы, которые полезнее демографического портрета
- «Почему эта категория каюты дороже?»
- «Есть ли две отдельные кровати?»
- «Подойдёт ли детям такого возраста?»
- «Что реально включено?»
- «Какие штрафы при отмене?»
- «Почему у вас дороже/дешевле Booking?»
- «Надо ли наряжаться на круизе?»
- «Где расположена каюта?»
- «Есть ли собственный пляж?»
- «Что будет, если цена изменится?»

## Как использовать
1. Выделить реальное возражение из продукта или переписки.
2. Ответить на него подтверждённым фактом.
3. Не выдумывать «страхи клиента» ради копирайтинга.
4. Сохранять реальные формулировки клиентов в этот файл по мере накопления.
