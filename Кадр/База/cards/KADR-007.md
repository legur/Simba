## Применение в Simba
Подходит для **продуктового круизного обзора** или прогревающего рилса: 15–25 секунд, одно УТП/особенность на сцену; можно собрать из собственных/лицензированных видеоклипов без генерации сложных эффектов. Для прямой продажи с ценой, датами, включениями и контактами уместнее дополнить этим стилем финальную карточку KADR-006 или иной согласованный формат.

**Быстро:** 5 коротких видеоблоков, 2 строки в каждом, бирюзовое выделение, карта, финальный «+»; обычные склейки и фоновая музыка, без платной анимации.

## Передача Монтажеру Клоду
1. Для мягкого продуктового проморолика с несколькими возможностями лайнера брать KADR-007; не путать со стилем оффера KADR-006.
2. Разбить на 5 блоков (введение / атмосфера корабля / развлечения / география / CTA), примерно 2,5–5 с каждый.
3. Каждая надпись — один тезис, максимум две строки; менять фон по смыслу, а не каждую секунду без необходимости.
4. Один акцентный цвет: бирюзовый (для этой версии). Не перегружать 3D, свечением или декоративными рамками.
5. Карту делать крупнее и читабельнее, чем мелкая вставка референса; страны и порты — только подтвержденные.
6. Финальный CTA «+ в комментариях» использовать только с реально организованной обработкой комментариев; для прямых заявок на WhatsApp заменить на явно утвержденное действие и телефон.
7. Возвращать начальный кадр для петли; отдельно проверить, что финальный CTA успевают прочесть. Проверять музыку и права до публикации, не угадывать по подписи плеера.
