# База монтажных приёмов Кадра

Владелец: самостоятельный аналитик **Кадр**. Потребитель: **Монтажер Клод**.
Назначение — для монтажа то же, что TIA для текстов: сохранять разборы референсов и находить применимые приёмы для нового задания. Это отдельная библиотека, не раздел TIA и не новые правила бренда.

## Использование монтажёром
Пошаговая инструкция с примерами записи и обратной связью: `Монтажер Клод/MONTAZHER_KLOD_v1.0.md`, §4 «Как пользоваться базой Кадра». При расхождении статуса в индексе и карточке не использовать её до уточнения; монтажёр не повышает статус сам.

Прочитать этот индекс перед выбором монтажных приёмов для новой сборки/существенной переработки ролика. По цели, сценам и тегам выбрать до трёх релевантных `READY` карточек и прочитать их целиком; можно использовать меньше или ни одной, если подходящих нет. Не добавлять чтение базы к каждой мелкой технической правке. Фиксировать в задании `KADR_REFERENCES: ID — применённый приём` либо `NONE — причина`. Не выдумывать непрочитанные карточки. Выбранные приёмы адаптировать под текущий сценарий, читаемость, инструменты и затраты; не переносить чужие факты и материалы.

## Пополнение Кадром
После реального просмотра и review сохранять в `cards/KADR-NNN.md` разбор одного референса с отдельно названными приёмами. Пользоваться `CARD_TEMPLATE.md`. Следующий свободный ID проверять по индексу и файлам; существующую карточку того же источника обновлять на месте, не плодить дубликаты. Сначала записать карточку, затем строку индекса, проверить ссылки и фактические статусы. Временные MP4/кадры/полный JSON остаются в video-lab; в Git — карточки и индекс.

`DRAFT` — разбор не завершён; `READY` — видео просмотрено, таймкоды/наблюдения проверены, способы применения и ограничения заполнены; `TEST` — технический тест; `SOURCE_BLOCKED` — видео недоступно. READY не подтверждает эффективность по охватам и не означает утверждение ролика Leo. Гипотезы внутри READY явно отмечаются. Недоказанные AI-определения не превращать в факты.

Поиск: сначала таблица/теги; при росте базы `rg -n -i "титры|ритм|переход|карточка|бит" "Кадр/База/cards"`, затем открыть найденные карточки. Кадр ведёт базу; монтажёр использует её и сообщает результат применения для обновления карточки. Единичный результат хранится как наблюдение, без автоматического обобщения.
