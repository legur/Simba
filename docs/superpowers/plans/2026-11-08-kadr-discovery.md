# Kadr Discovery Implementation Plan

**Goal:** По запросу находить подходящие рилсы и разбирать лучшие для базы Кадра.
**Architecture:** Агент использует доступный веб-поиск, затем существующий анализ/review и запись карточек. Новый сервис не создаётся.
**Tech Stack:** Markdown runtime, доступные веб-инструменты, существующий Python адаптер.
**Spec:** `docs/superpowers/specs/2026-11-08-kadr-discovery-design.md`.

## Ограничения
Только по запросу; до 8 кандидатов / до 3 попыток анализа по умолчанию. Никаких новых зависимостей, платного API или расписания. Чужие локальные изменения не включать в доставку. Найденная ссылка не READY.
