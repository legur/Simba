# Кадр — план интеграции

Цель по поручению Leo: установить rea-video в Simba. Уточнение: самостоятельный Кадр ведёт базу приёмов для монтажёра, аналогично TIA для Simba; не разовый встроенный советчик. Канонический индекс `Кадр/База/INDEX.md`, карточки `cards/KADR-NNN.md`, статусы DRAFT/READY/TEST/SOURCE_BLOCKED. Монтажёр ищет и читает до трёх подходящих READY-карточек перед выбором приёмов новой сборки.

Решение исполнителя: имя «Кадр», отдельный нетекстовый аналитик референсов. Существующие авторы не дают технический разбор чужого видео; монтажёр собирает результат, поэтому анализ имеет отдельный вход и выход. Локальное окружение Python 3.12 в video-lab/.venv-rea, upstream в video-lab/tools/rea-video. Альтернатива — лишь инструкция монтажёру — не обеспечивает установленного инструмента; платный VLM не нужен для первого запуска.
