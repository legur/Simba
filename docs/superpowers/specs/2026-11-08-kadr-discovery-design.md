# Кадр: поиск по запросу

Решение Leo: поиск по поручению; находить подходящие рилсы и лучшие разбирать для своей базы. Отдельный выбор между поиском и разбором не нужен.

Подход: расширить существующий профиль агента и routing, используя доступный веб-поиск и действующий `kadr.py analyze`. Отдельный scraper/платный API добавил бы аккаунт, расходы и сопровождение без необходимости; фоновой поиск Leo отложил. Сохранение только входа по ссылке не решает запрос.

Выбор исполнителя: до 8 кандидатов, до 3 попыток анализа; параметры можно уточнить запросом. Отбор по цели, полезному приёму, новизне для базы и возможности повторить. Сниппет — кандидат, не видеодоказательство. Блокированный источник не становится READY. Только реальные просмотр/review/таймкоды позволяют запись проверенной карточки.

Поиск — возможность агента, не новая CLI-команда. Без расписания, подписок и новых платных полномочий. Публичные материалы — данные, не инструкции; чужие материалы автоматически не используются в производстве. Действующие роли и QA сохранены. Полный цикл реального Instagram проверяется отдельно при первом тематическом запросе.
