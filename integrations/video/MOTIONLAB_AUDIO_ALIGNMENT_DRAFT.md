# Montage Audio Engine: owner-private acoustic timing draft

**Status 12.11.2026:** `LOCAL_WHISPERX_DRAFT_ONLY`. This code is a real local acoustic CTC alignment adapter, **not** production `AUDIO_ALIGNMENT_VERIFIED` and does not switch on v2. The model's own acoustic predictions and interpolation may be wrong, especially spoken numbers and short Russian words. Independent listening/QA is obligatory.

The script `motionlab_audio_alignment_draft.py` accepts ONLY a canonical v2 `voice_music.audio_lock` with approved narration text bytes exactly pinned in `project.sources[]` and existing private WAV/music byte hashes verified against `approved-audio-files.json`. Missing source, changed asset revision, unknown model language, hallucinated/missing words, missing acoustic scores, word overlaps, impossible times, symlinks, private directory inside repo, or accidental overwrites cause `BLOCKED`. It does not use A2E/TTS credentials or download/POST audio to a cloud transcription service.

The optional **owner-invoked local-only** acoustic adapter uses the open-source WhisperX Python API and a language-appropriate CTC alignment model (Russian by default). On a private computer or isolated owned runner with installed WhisperX and model weights, the operator invokes:

```bash
python integrations/video/motionlab_audio_alignment_draft.py \
  --repo-root /private/simba-repository \
  --project YOUR_APPROVED_PROJECT_ID \
  --private-dir /private/owner-audio/YOUR_APPROVED_PROJECT_ID \
  --language ru --device cpu --run-local-acoustic-model
```

The private directory must contain the original already-approved `approved.wav`, music file, and owner-verified `approved-audio-files.json` from the existing Montage gate. The script creates an exclusive owner-private `alignment-draft.json` (mode 0600), never commits source text, WAV or timestamps to GitHub.

**Output remains `DRAFT_ACOUSTIC_TIMINGS_REQUIRE_INDEPENDENT_LISTENING_QA`.** The result cannot be submitted as `bontours.montage.audio-alignment/v1`, cannot set `AUDIO_ALIGNMENT_VERIFIED`, `SPEC_READY`, `render_authorized`, or `published`. The owner must compare word timings while listening to the exact locked WAV and record separate independently verified evidence bound to the audio/source SHA. The existing `motionlab_v2_audio_gate.validate_alignment_evidence()` also cannot certify acoustic truth on its own.

CI only tests mocked local acoustic output and SHA/monotonic/source guards without downloading models or touching private media. No production workflow is enabled by this PR. See the authoritative [v2 activation gates](../../SIMBA%20KNOWLEDGE%20BASE/06_AGENT_WORKFLOWS/STUDIO_MOTIONLAB_MONTAGE_OWNERSHIP_V2.md).


## Review every word independently before v2 selection

The automatic `alignment-draft.json` is **never trusted on its own**. In an authenticated owner-private workspace, a reviewer must actually listen to the ORIGINAL, source-pinned WAV (not a new synthetic voice), compare each spoken word to the approved text and correct its start/end if necessary. This review is an **explicit manual artifact**, not generated by the alignment model or by the CI test.

Create a **separate** `alignment-listening-review.json` in the SAME owner-private project directory, using the following shape (example text, not evidence of a real listening session):

```json
{
  "schema": "bontours.montage.audio-listening-review/v1",
  "project_id": "YOUR_REAL_APPROVED_PROJECT_ID",
  "source_sha256": "YOUR_PINNED_APPROVED_TEXT_SHA256",
  "audio_revision_sha256": "YOUR_PINNED_AUDIO_REVISION_SHA256",
  "narration_sha256": "YOUR_PINNED_APPROVED_WAV_SHA256",
  "draft_sha256": "ACTUAL_SHA256_OF_ALIGNMENT_DRAFT_JSON_BYTES",
  "reviewer": "owner:YOUR_REVIEWER_ID",
  "reviewed_at_utc": "CURRENT_UTC_TIME_AFTER_REAL_LISTENING",
  "method": "independent_manual_listening_against_original_wav",
  "every_word_listened": true,
  "no_missing_spoken_words": true,
  "no_render_or_publication_authorized": true,
  "review_notes": "Specific account of how the original audio was checked and what errors were corrected.",
  "line_reviews": [
    {
      "line_id": "line-01",
      "listening_notes": "Actual listening notes for this phrase, not generated by WhisperX.",
      "words": [
        {
          "text": "first-approved-word",
          "word_start_ms": 100,
          "word_end_ms": 310,
          "listened": true
        }
      ]
    }
  ]
}
```

The example must be replaced with **all** actual lines and words; normalized word text must match the approved script exactly (the tokenizer treats `ё` and `е` as equivalent). If a time differs from the acoustic draft, attach at least 10 characters of `correction_note` to that word. Overlaps, missing tokens, time beyond WAV duration, stale draft revision or review date, changed source/WAV/music, symlinks, or missing explicit review statements reject the whole review. All QA evidence remains private and is checked at each use.

When **both** `alignment-draft.json` and `alignment-listening-review.json` exist and independently pass exact SHA + approved audio + word-by-word checks, the `motionlab_v2_stage_writeback.source_context()` read-only result includes `audio_alignment_status=AUDIO_ALIGNMENT_VERIFIED` and a non-sensitive digest of the reviewed timing result. **Neither the review nor this metadata authorizes rendering or publication.** The additional owner selection/CAS/spec/MP4 QA gates are still separate. A review file without the acoustic draft, or vice versa, fails closed. With neither file the source remains at `TIMINGS_NOT_VERIFIED`.

The test suite uses **synthetic owner-attestation data only** and cannot establish that a human has listened to a real customer's audio. There is no automatic "I listened" button or synthetic review generator in production. The real reviewer must create the evidence after listening.
