# Simba Киностудия — Rafael в ChatGPT (шаг 5C, экспериментальный адаптер)

Дата: 2026-11-10. Канонический production-процесс: `SIMBA KNOWLEDGE BASE/06_AGENT_WORKFLOWS/VIDEO_PIPELINE.md`.

## Где исполняется

**ChatGPT** — создание трех раскадровок с помощью встроенной генерации изображений. **GitHub Actions** — только задачи, тесты и проверяемый диспетчер; он не вызывает ChatGPT image generation. **Google Drive** (`Simba Private AI Drafts`) — закрытый архив результатов.

Принцип: наличие GitHub Issue, текста промпта или упаковщика изображений **не означает**, что Рафаэль создал файл. Настоящим выполнением считается наличие реальных файлов, подтвержденных размеров/хешей и проверенной записи в приватном архиве.

## Что делает `chatgpt_rafael.py`

1. Читает `campaigns/<project-id>/project.json` из существующего каталога.
2. Валидирует `handoff.make_handoff`: следующий этап **storyboard**, получатель **RAFAEL**, выбранный сценарий **approved**, источник не устарел.
3. В режиме `--prepare-only` выводит три художественно отличающихся направления, не запуская генерацию.
4. Принимает **девять реальных PNG**, раскладываемых по `option_1/scene_1.png` … `option_3/scene_3.png`, и запись о запуске ChatGPT.
5. Проверяет декодируемость всех изображений, размеры, уникальность SHA-256, преобразует копии в 9:16, делает три контактных листа.
6. Сохраняет ZIP с изображениями и manifest.json; сверяет ZIP побайтно.
7. Оставляет статус **STORYBOARD_OPTIONS_NEED_LEO** и `archive_verified=false`. Нет разрешения выбирать за Лео, передавать задачу в A2E или публиковать.

Изображения должны быть созданы встроенным image tool в ChatGPT; адаптер **не обращается** к Ollama, внешним фотостокам или платным API. SHA-256 подтверждает байты, но сам по себе не доказывает, какая модель их нарисовала. Это поле требует отдельного журнала ChatGPT generation receipts.

## Изменения, которые еще требуются для полного 5C

- Получить в ChatGPT выбранный `script` из приватного архива и доказуемый receipt исходника.
- Подключить штатную передачу файлов из ChatGPT в закрытый Drive, подтвердить SHA/размер/права доступа **чтением обратно**.
- Показать Лео три *полные* наглядные раскадровки с привязкой к репликам и реальной длительностью.
- Записать **только после выбора** в `stage_handoffs.storyboard`: `state=approved`, `options_presented=3`, `options_evidence`, `selected_option`, `approval_evidence`, `input_fingerprint` и проверенный `assets` с типом `storyboard`.
- Перепроверить handoff и только потом поручить Сценаристу создание A2E-промптов. Платные вызовы без лимита запрещены.
