# Поиск материалов и продолжение проектов

Пилот на Праге и Баварии. Бесплатный локальный инструмент на Python 3.10+, только стандартная библиотека. Нет установки сервиса, платного API, Notion, сетевых запросов или генерации медиа.

## Использование

Из корня полного checkout `legur/Simba`:

```bash
python3 integrations/materials/catalog.py list
python3 integrations/materials/catalog.py resume Бавария
python3 integrations/materials/catalog.py reuse Бавария --kind animated_clip
python3 integrations/materials/catalog.py search "крупные титры" --library kadr
python3 integrations/materials/catalog.py search "Прага" --library critic
python3 integrations/materials/catalog.py check
```

Для машинного результата поставьте `--json` перед командой. Для другого checkout: `--root /path/to/Simba` перед командой. На Windows вместо `python3` может использоваться `python`.

Поиск читает существующие AR-, TIA-, KADR-карточки, журналы Критика, Content Library и `campaigns/*/project.json`. Он работает с фактически имеющимися локальными файлами, без полной копии архива в контексте агента. Фраза разбивается на слова: все слова должны встречаться в документе или пути. Это текстовый поиск, не семантический подбор и не экспертное утверждение пригодности.

Результат показывает исходный статус и путь. Агент открывает полную карточку, проверяет актуальный индекс и правила выбранной роли. TEST, DRAFT, SOURCE_BLOCKED и неизвестный статус не становятся проверенными рекомендациями. Архивные/проблемные разделы `99_*` не включаются в обычную выдачу.

## Как продолжать проект

1. Обновить checkout из `main`, либо прочитать актуальные файлы через GitHub-инструменты.
2. Найти проект в [реестре](../../campaigns/README.md), открыть его `project.json` и перечисленные `sources`.
3. Выполнить `resume`. Команда сверяет SHA-256 текстов источников. `STALE_SOURCE` означает: сначала прочитать изменившийся источник и согласовать состояние карточки; прежний `next_action` не исполнять автоматически. Возвращается exit code 2.
4. Сверить последнюю текущую правку Лео: сообщения другого чата могут быть новее файлов. Контроль SHA обнаруживает изменения только локально прочитанных файлов, не чужую переписку или замену медиа на Drive.
5. Через `reuse` найти сохраненные исходники; открыть реальный файл и проверить его перед использованием. `recorded_size_bytes`, `recorded_sha256`, `evidence` — сведения из исходной сессии, а не новая проверка внешнего файла.
6. Выполнить только требуемую роль и стадию по действующему workflow. Каталог не выдает разрешения на синтез/анимацию, платный повтор или публикацию.
7. После стадии обновить существующую каноническую сессию, затем тот же `project.json`: новые ссылки, состояние, следующий шаг, отсутствующее, выбранную рабочую версию. Пересчитать `sources[].sha256` по точным байтам актуального файла. Записать оба изменения одним коммитом и проверить read-back.

Готовая контрольная команда для хеша:

```bash
python3 -c "import hashlib,pathlib; print(hashlib.sha256(pathlib.Path('путь-к-источнику').read_bytes()).hexdigest())"
```

Не переписывать хеш, чтобы скрыть неизвестное изменение. Сначала сверить смысл новой редакции. Не обновлять карточку только по названию `final` или дате файла.

## Данные проекта

`project.json` — компактный указатель состояния, а не копия сценария или правил агента. Одна запись на постоянный `id`. Переиспользуемые знания остаются в своих библиотеках с исходными AR/TIA/KADR-ID.

- `sources`: основные тексты и отпечатки прочитанных редакций.
- `stage`, `next_action`, `missing`: место продолжения работы.
- `assets`: только реально найденные стабильные ссылки; сохраненные размеры/хеши явно помечены `recorded_*`.
- `working_asset_id`: версия для текущей работы, не утвержденный финал.
- `approved_asset_id`: конкретный утвержденный файл либо `null`.
- `approvals`: отдельные editorial/publication; `approved` требует отдельного evidence.
- `references`: исходные карточки и характер связи. Не объявлять карточку примененной только потому, что она найдена.
- `latest_user_request`: конкретная более поздняя правка, когда источник еще не содержит ее исполнения.

Повторный поиск и чтение не меняют файлы. Автоматического обновления из других чатов нет. Инструмент не меняет права Google Drive и не считает сохранение файла подтверждением публикации.

## Проверка

```bash
python3 -m unittest discover -s integrations/materials -p test_catalog.py -v
python3 integrations/materials/catalog.py check
```

Проверяются устаревание/отсутствие источников, неоднозначный проект, статусы, дубли ID, выбранные файлы, доказательство утверждения, временные URL и выход пути за checkout. Доступность и содержимое внешних файлов проверяются выбранным исполнителем отдельно.
