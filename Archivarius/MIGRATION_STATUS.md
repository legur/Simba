Миграция считается завершённой только после:
1. физического переноса всех требуемых карточек;
2. сравнения количества файлов по категориям;
3. проверки AR-ID / duplicate status;
4. проверки active/draft/needs_fix/archive/duplicate;
5. контрольного RELEASE-STRICT;
6. явного переключения Archivarius source-of-truth на GitHub.


### Ограничение записи карточек

Физический перенос AR-карточек через текущий GitHub-коннектор остановлен защитой OpenAI: карточки содержат prompt/instruction payload, и операция записи такого содержимого в GitHub блокируется даже при переносе одной карточки через промежуточный локальный файл.

Это ограничение относится к каналу переноса, а не к целостности исходных данных. Исходные карточки остаются на Google Drive без изменений.
