## Ограничения проверки

Сравнение Google Docs относится к читаемому текстовому представлению. Сохраняемые индексы содержат исторические сведения; наличие карточек подтверждается манифестом и Git tree. Архивные цены и условия не проверялись как текущие. Проверка всех полей карточек, broken references и samples относится к отдельному RELEASE-STRICT.

На Windows 21 исторический путь манифеста из исходного снимка недоступен через обычный `Path.is_file()` из-за запрещённых символов `:`/`|` или ограничения длины пути. Эти записи не менялись в точечном ремонте: все 2872 исходные ссылки присутствуют в Git tree базового снимка, а изменённые записи и их runtime-пути доступны отдельно. Поэтому целостность полного набора следует проверять по Git tree/index, а не только по локальной файловой системе Windows.
