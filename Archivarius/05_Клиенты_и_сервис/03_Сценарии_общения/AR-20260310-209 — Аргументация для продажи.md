## Описание
Подготовить сильную аргументацию для продажи, используя официальные маркетинговые материалы.

## Раздел
6. Отдел продаж

## Prompt (русский)
Мне нужно создать убедительные аргументы в пользу того, почему [клиент] должен внедрить [продукт] для решения [их болевых точек]. Напиши конкретные причины, по которым [продукт] от [компании] может помочь им достичь их [бизнес-целей], используя @[Полный комплект материалов для отдела продаж].


## Prompt (original)
I need to create convincing reasons why [customer] should adopt [product] to solve for [their pain points]. Write specific reasons why [product] from [company] could help them achieve their [business goals] using @[Product Sales Kit Full Assets].


## Примеры использования
Работа с возражениями, создание продающего слайда, формирование индивидуального оффера.


## Notes
Импортировано из Excel-таблицы с промтами.
