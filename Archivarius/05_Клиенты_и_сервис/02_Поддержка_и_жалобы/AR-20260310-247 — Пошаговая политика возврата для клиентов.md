## Описание
Сделать сложную юридическую инструкцию простой и понятной для людей. Короткий список действий снижает нагрузку на операторов.

## Раздел
9. Служба поддержки

## Prompt (русский)
Обобщи этот контент, чтобы написать четкие и краткие правила возврата товара, и выдели 5 шагов, которые должен предпринять клиент по порядку.


## Prompt (original)
Summarize this content to write a clear and concise product return policy and outline 5 steps for customers to take in sequential order.


## Примеры использования
Пошаговый гайд по возврату через пункт выдачи, инструкция по оформлению брака, памятка «Как вернуть деньги».
