## Описание
Сделать расписание на неделю для новичка с именами коллег и списком важных встреч.

## Раздел
11. Отдел кадров

## Prompt (русский)
Создай таблицу с графиком первой рабочей недели нового сотрудника, включая основные встречи, учебные занятия и знакомства. Предусмотри столбец для основных контактов и уровня приоритета (низкий, средний, высокий) для каждого мероприятия.


## Prompt (original)
Create a table that outlines a new employee’s first-week schedule, including key meetings, training sessions, and introductions. Provide a column for key contacts and priority level (low, medium, high) for each activity.


## Примеры использования
План на неделю, Расписание адаптации, Введение в должность, Календарь нового сотрудника
