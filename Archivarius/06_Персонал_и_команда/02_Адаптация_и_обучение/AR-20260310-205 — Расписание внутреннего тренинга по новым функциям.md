## Описание
Составить четкое расписание внутреннего тренинга по новым функциям продукта.

## Раздел
6. Отдел продаж

## Prompt (русский)
Создай повестку дня на полдня для обучающей сессии по нашей последней технологии [продукты] для отделов продаж. Включи время для презентации команды разработчиков и время на обед.


## Prompt (original)
Create a half-day agenda for an educational session on our latest technology [products] for sales teams. Include time for the product development team to present and include time for lunch.


## Примеры использования
Обучение новичков, презентация обновлений софта, воркшоп по продажам.
