## Описание
Придумать глубокие вопросы для интервью на основе требований к конкретной должности.

## Раздел
11. Отдел кадров

## Prompt (русский)
Я рекрутер и готовлюсь к собеседованию с кандидатами. Используя описание вакансии в файле, который я загружаю, составь список из 20 открытых вопросов для собеседования, которые я могу использовать для отбора кандидатов.


## Prompt (original)
I am a recruiter, and I am preparing for candidate interviews. Using the job description in the file I’m uploading, write a list of 20 open-ended interview questions that I can use to screen candidates.


## Примеры использования
Подготовка к собеседованию, Оценка компетенций, Скрининг кандидатов, Интервью по компетенциям
