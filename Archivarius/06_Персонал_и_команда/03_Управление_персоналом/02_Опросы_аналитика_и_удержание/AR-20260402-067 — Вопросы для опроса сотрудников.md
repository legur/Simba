# Составить вопросы для опроса сотрудников

## Prompt

```text
Напиши 6–8 вопросов для опроса сотрудников, предназначенных для измерения [например, чувства принадлежности, доверия к руководителю, баланса рабочей нагрузки]. Убедись, что вопросы нейтральны и легки для понимания. Оформи их по одному вопросу на строку с предложениями по шкале оценки.
```
