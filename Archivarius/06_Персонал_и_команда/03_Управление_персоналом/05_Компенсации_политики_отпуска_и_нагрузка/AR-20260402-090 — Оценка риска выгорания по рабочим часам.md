# Определить риск выгорания на основе отработанных часов

## Prompt

```text
На основе этих данных табеля учёта рабочего времени (количество часов, зарегистрированных каждым сотрудником за неделю), выяви любые ранние признаки риска выгорания. Используй порог >45 часов в течение 2+ недель. Верни сводку по сотрудникам с выявленными рисками и тенденциями в среднем количестве часов.
```
