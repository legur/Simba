## Пост
Задание на день 2:
сделать анимацию генерации с дня 1 и отдельно создать lip sync через Grok.

Это не один готовый промт, а шаблон для создания своих промтов под разные сцены и персонажей.

## Шаги
1. Возьмите генерацию или персонажа из дня 1.
2. Соберите промт для анимации по универсальной формуле:
   [Тип съемки/Камеры] + [Основной объект] + [Действие] + [Окружение/Свет] + [Стиль и Качество]
3. Сгенерируйте анимированную сцену.
4. После этого подготовьте отдельный lip sync prompt для Grok.
5. Вставьте в lip sync prompt:
   • кто говорит
   • текст реплики
   • язык
   • тип голоса
   • требование к качеству синхронизации

## Шаблон промта
```text
[Тип съемки/Камеры] + [Основной объект] + [Действие] + [Окружение/Свет] + [Стиль и Качество]
```

## Промпты

### Prompt 1 - пример для анимации
```text
Cinematic wide shot, a mermaid with flowing turquoise hair looking at a golden compass, glowing underwater particles, sunlight rays shifting through the water, hyper-realistic, 4k, smooth animation.
```

### Prompt 2 - тот же пример на русском
```text
Кинематографический общий план, русалка со струящимися бирюзовыми волосами, смотрящая на золотой компас, светящиеся подводные частицы, солнечные лучи, скользящие по воде, гиперреалистичная, 4K, плавная анимация.
```

### Prompt 3 - пример для lip sync
```text
Make this mermaid talk. Script: "Этот компас указывает не на север, а туда, где спрятаны твои мечты." Use a soft feminine voice in Russian. Ensure high-quality lip-sync.
```

## Примечания
• Карточка относится к типу guide, а не prompt.
• Это конструктор для создания других промтов.
• Формула подходит для сказочных, рекламных и персонажных сцен.
• Для lip sync можно менять:
  • voice style
  • language
  • emotion
  • intensity
• Если нужна серия упражнений, карточку можно расширить до prompt_pack.
