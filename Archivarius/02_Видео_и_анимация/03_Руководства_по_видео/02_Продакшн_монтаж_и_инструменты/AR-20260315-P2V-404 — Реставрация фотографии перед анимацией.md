# AR-20260315-P2V-404

## Реставрация + анимация

**Type:** methodology_card  
**Category:** photo_to_video  
**Use case:** старые поврежденные снимки, слабое качество, семейные архивы

### Назначение
Использовать двухэтапный процесс: сначала восстановить качество снимка, затем анимировать.

### Алгоритм
1. Улучшить исходное фото: резкость, шум, дефекты, лицо, глаза.
2. Проверить, что после улучшения не потерялась похожесть.
3. Только после этого запускать мягкую анимацию.

### Рабочий промт для второго шага
```text
Using the restored version of this portrait, create a subtle realistic animation with gentle blinking, soft breathing, and minimal head motion. Preserve restored facial details, age impression, original likeness, and historical mood. Keep the motion respectful and natural.
```

### Почему это работает
Плохое исходное фото часто ломает глаза, рот и кожу во время анимации. Реставрация уменьшает этот риск.

### Когда использовать
- старые семейные архивы
- фото с шумом и низким разрешением
- потертые, выцветшие или слегка поврежденные изображения

### Риск
Если реставрация слишком агрессивная, анимация будет строиться уже по «подмененному» лицу.
