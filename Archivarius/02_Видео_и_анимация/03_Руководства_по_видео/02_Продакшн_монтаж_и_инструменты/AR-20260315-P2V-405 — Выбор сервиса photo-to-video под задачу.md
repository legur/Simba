# AR-20260315-P2V-405

## Как выбирать сервис под задачу

**Type:** guide_card  
**Category:** photo_to_video_selection

### Назначение
Не выбирать инструмент по месту в рейтинге, а под тип результата.

### Матрица выбора

**1. Старый архивный портрет**  
Ищем сервис, который хорошо делает:
- subtle blink
- minimal motion
- face restoration
- respectful realism

**2. Личное фото для соцсетей**  
Ищем сервис, который дает:
- мягкую мимику
- быстрый экспорт
- простой интерфейс
- хороший результат на одном лице

**3. Cinematic / lifestyle / travel**  
Ищем сервис, который умеет:
- motion beyond the face
- hair / clothing / background movement
- better scene continuity
- prompt control

**4. Фото плохого качества**  
Ищем связку:
- restoration first
- animation second

### Критерии сравнения
- насколько хорошо сохраняется похожесть
- насколько естественно моргают глаза и двигается рот
- двигает ли сервис только лицо или всю сцену
- есть ли контроль промтом
- есть ли артефакты в зубах, веках, волосах, очках
- насколько быстро экспортирует
- есть ли watermark и лимиты

### Практическое правило
Не существует «лучшей нейросети вообще». Есть лучшая нейросеть под конкретный тип оживления.
