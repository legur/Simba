# AR-20260315-VEO-304

## Title
Veo 3.1: Start/End Frame Control in Flow

## Type
prompt_card

## Platform
Flow

## Purpose
Задавать не просто содержание клипа, а направленный переход между двумя конкретными состояниями сцены.

## When to use
Для монтажной логики, трансформаций, долли-движений, reveal-сцен, переходов до/после, начала и финала эпизода.

## Core logic
Добавить start frame и end frame, затем текстом описать только то действие или переход, который должен случиться между ними.

## Prompt template
Begin from the uploaded start frame and transition naturally to the uploaded end frame. Preserve the key subjects and scene logic while creating a smooth visual progression between the two states. Action/transition: [transition]. Camera motion: [camera]. Timing: [timing]. Mood: [mood]. Make the motion feel intentional and coherent.

## Short version
Start from frame A, end on frame B. Smooth transition. [Transition]. [Camera]. [Timing].

## Control fields
- start_frame: required
- end_frame: recommended
- transition: required
- camera: recommended
- timing: optional
- coherence_lock: required

## Notes
Frames особенно полезны там, где текст плохо удерживает геометрию изменения.
Не стоит одновременно перегружать transition сложной драматургией и множеством новых объектов.
