# AR-20260315-VEO-305

## Title
Veo 3.1: Reference Limits and Model Constraints

## Type
guide_card

## Platform
Gemini API / Vertex AI / Flow ecosystem

## Purpose
Фиксировать технические ограничения, чтобы не писать промты вразрез с моделью.

## Key constraints
- Veo 3.1 supports up to 3 reference images for image-based direction.
- In Vertex AI docs, Veo 3.1 supports asset reference images, but not style reference images.
- For style-image workflows, Google docs point to veo-2.0-generate-exp instead.
- Frame-specific generation supports specifying first and/or last frames.
- Native portrait generation 9:16 is supported in Veo 3.1 workflows.

## Practical implication
Если нужен контроль персонажа, объекта и среды — три референса обычно и есть рабочий максимум.
Если нужен именно style reference, нельзя рассчитывать на Veo 3.1 как на основной режим.
Если задача про переход между состояниями, лучше использовать frames, а не пытаться полностью описать переход только словами.
