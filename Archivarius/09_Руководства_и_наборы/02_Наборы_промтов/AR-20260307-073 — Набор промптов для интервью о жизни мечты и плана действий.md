## Описание
Набор из трех последовательных промтов для самопознания, определения желаемой жизни, построения плана действий и оценки сроков достижения целей.

## Структура
Пакет состоит из 3 промтов:
1. Интервью для выявления истинных желаний
2. План по дням
3. Оценка сроков достижения

## Prompt 1 — Интервью

Привет, возьми у меня пожалуйста интервью, которое поможет выяснить мои истинные желания, цели и узнать что является жизнью моей мечты.

## Prompt 2 — План действий

Основываясь на результатах моего интервью создай для меня план по дням как мне достичь этой жизни?

## Prompt 3 — Сроки достижения

Если я буду ежедневно придерживаться твоего распорядка недели в какие сроки я достигну жизни своей мечты?

## Рекомендуемый порядок использования
1. Сначала пройти интервью полностью и отвечать подробно
2. Затем на основе ответов запросить план по дням
3. После этого запросить оценку сроков
4. При желании повторять цикл раз в 1-3 месяца для корректировки целей

## Notes
Лучше всего работает:
- при честных и подробных ответах
- в формате длинного диалога
- с уточнениями после первого интервью

Подходит для:
- личного планирования
- коучинговых сессий
- саморефлексии
- постановки целей
