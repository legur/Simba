## Пост
Короткий набор пользовательских инструкций для ChatGPT, который повышает управляемость ответов: добавляет ID к каждому сообщению, убирает эмодзи и заставляет модель объяснять, почему созданный ею промпт должен работать.

Это не один промт, а пакет постоянных правил для раздела **«Пользовательские инструкции» / «Персонализация»**.

## Что внутри
### 1. ID для каждого ответа
Помогает ссылаться на конкретный ответ по номеру в длинных диалогах.

### 2. Запрет на эмодзи
Убирает лишние смайлики из обычных ответов.

### 3. Объяснение «Почему это работает»
Полезно, если ChatGPT пишет промпты для других ИИ, особенно для генерации изображений и кода.

## Инструкция
1. Открой настройки ChatGPT.
2. Перейди в раздел **«Персонализация»**.
3. Вставь нужные блоки в пользовательские инструкции.
4. Используй не все сразу, а только те правила, которые реально помогают твоему сценарию работы.

## Тексты для пользовательских инструкций
### Блок 1. Нумерация ответов
```text
Для каждого твоего ответа (всех ответов, включая простые процедурные ответы) начни с указания уникального идентификатора (в формате "ID: XXX", где XXX — это порядковый номер целого числа, начинающийся с 001), чтобы я мог впоследствии ссылаться на любой твой ответ по номеру, и ты знал, о каком ответе я говорю в наших разговорах.

При ответе на текстовые вопросы, пожалуйста, нумеруй каждый ответ. При ответе на устные вопросы не нумеруй ответы.
```

### Блок 2. Убрать эмодзи
```text
В своих ответах не используй смайлики, если тебя об этом специально не попросили, даже если тебя просят писать на уровне детского восприятия. Никаких смайликов. Никогда.
```

### Блок 3. Объяснение для промптов
```text
При создании промптов для других инструментов искусственного интеллекта обязательно включи в ответ объяснение «Почему это работает».
```

## Когда это полезно
- если диалоги длинные и нужно ссылаться на старые ответы
- если раздражают эмодзи в рабочих ответах
- если ты учишься писать промпты и хочешь видеть не только результат, но и механику

## Ограничения и замечания
- Нумерация ответов может конфликтовать с некоторыми форматами общения, где важна естественность или краткость.
- Не каждая модель стабильно соблюдает глобальный запрет на эмодзи в 100% случаев.
- Блок «Почему это работает» полезен для обучения, но иногда делает ответы длиннее, чем нужно.

## Минимальная рабочая версия
Если нужен короткий набор без перегруза, можно оставить только два правила:
```text
В своих ответах не используй смайлики, если тебя об этом специально не попросили.

При создании промптов для других инструментов искусственного интеллекта обязательно включи в ответ объяснение «Почему это работает».
```
