## Пост
Короткая универсальная формула для сборки сильного запроса к нейросети:
**РОЛЬ + ЗАДАЧА + КОНТЕКСТ + ФОРМАТ + ОГРАНИЧЕНИЯ**.

Подходит как базовый каркас для текстов, анализа, писем, таблиц, идей и рабочих инструкций.

## Формула
**Роль** — кто отвечает
Пример: «Ты HR-менеджер»

**Задача** — что нужно сделать
Пример: «Напиши описание вакансии frontend-разработчика»

**Контекст** — для кого, где и зачем
Пример: «Для публикации на hh.ru»

**Формат** — в каком виде выдать результат
Пример: «Заголовок + обязанности + требования + условия»

**Ограничения** — что исключить и где поставить рамки
Пример: «Без фразы “дружный коллектив”. Зарплата: 200-300т₽.»

## Промпт
```text
РОЛЬ + ЗАДАЧА + КОНТЕКСТ + ФОРМАТ + ОГРАНИЧЕНИЯ

🔹 Роль: «Ты [кто]»
🔹 Задача: «Сделай [что]»
🔹 Контекст: «Для [кого / зачем]»
🔹 Формат: «В виде [списка / таблицы / письма / 3 абзацев]»
🔹 Ограничения: «Без [чего] / Не более [сколько]»
```

## Полный пример
```text
Ты HR-менеджер. Напиши описание вакансии frontend-разработчика. Для публикации на hh.ru. Формат: заголовок + обязанности (5 пунктов) + требования (5 пунктов) + условия. Без фраз "дружный коллектив". Зарплата: 200-300т₽.
```

## Как применять
Простой вопрос:
достаточно **задачи + формата**.

Сложная задача:
лучше использовать все 5 элементов.

Рабочее правило:
чем выше цена ошибки, тем важнее явно прописать контекст, формат и ограничения.

## Универсальный шаблон
```text
Ты [роль].
Сделай [задача].
Контекст: [для кого / где будет использоваться / с какой целью].
Формат: [структура ответа].
Ограничения: [что исключить, лимит объема, тон, запреты, обязательные данные].
```

## Примечания
Сильная сторона формулы — она быстро снижает расплывчатость запроса.

Слабое место — сама по себе формула не гарантирует качество, если:
- не даны факты
- нет критерия качества
- задача слишком большая и не разбита на шаги

Практичное усиление:
для рабочих задач часто полезно добавить шестой элемент:
**критерий качества / критерий приемки**.

Пример:
«Текст должен быть понятным человеку без технического бэкграунда, без воды, до 1200 знаков.»
