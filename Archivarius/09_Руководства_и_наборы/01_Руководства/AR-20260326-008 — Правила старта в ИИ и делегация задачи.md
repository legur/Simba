## Пост
Короткая практическая схема для новичков по входу в ИИ: сначала разобраться в технической базе, затем разложить свои реальные задачи на шаги, после чего передать этот процесс нейросети через простые рабочие запросы. Материал дополнен примером на задаче переделки лендинга для роста конверсии.

## Главная мысль
Не начинать с магии и “идеального промпта”.

Правильный порядок такой:
1. понять инструмент технически
2. описать собственный процесс решения задачи
3. только потом передать этот процесс модели

## 3 правила для новичков
### 1. Сначала разобраться технически
Нужно понять:
- какие кнопки за что отвечают
- какие модели под какие задачи подходят
- как работают GPTs, Gems, проекты и контекст
- какой контекст помогает, а какой только засоряет диалог

### 2. Разложить задачи и процессы
Нужно выписать:
- повторяющиеся задачи за неделю
- последовательность действий внутри каждой задачи
- свою экспертную логику, которую обычно держишь в голове

Ключевая идея:
нейросеть не может качественно додумать процесс за человека, если сам процесс не оцифрован.

### 3. Передать процесс нейросети
Когда техническая часть понятна, а процесс уже описан, делегирование перестает быть хаосом.

Тогда ИИ получает не абстрактное “сделай хорошо”, а понятную структуру действий.

## Пример workflow: переделка лендинга для увеличения конверсии
### Шаг 1. Критика текущего лендинга
```text
Посмотри на мой сайт, как специалист по конверсионному маркетингу, который специализируется на веб-сайтах, отражающих ценности компаний и обладающих высокими конверсиями.

У меня есть (продукт) для (ЦА). Тебе нужно раскритиковать структуру и тексты лендинга, а затем на втором этапе мы создадим новую версию. Вот скрины лендинга.
```

### Шаг 2. Логика принятия решения
```text
Стань стратегическим маркетологом, специализирующимся на психологии принятия решения о покупке.

Наша аудитория (чуть больше про ЦА), по каким критериям ЦА решает купить продукт и классифицируй это через "лестницу потребностей Ханта".
```

### Шаг 3. Внутренние вопросы ЦА
```text
Напиши 10 вопросов, которые задает себе ца, на каждом этапе, как будто ты читаешь его мысли в голове.
```

### Шаг 4. Структура и заголовки по 4U
```text
Ты копирайтер, который передает атмосферу и эмоции, но при этом очень конкретен и специализируется на конверсионных текстах.
Предложи структуру конверсионных структур и напиши заголовки конкретные, триггерные, с числами, фактами по формуле 4U полезные и захватывающие.
```

### Шаг 5. Полный текст страницы
```text
Напиши полный и детализированный текст для странички по структуре выше. Убедись, что каждый элемент текста точно отображает ценности и попадает в потребности ЦА, подчеркивает УТП и направлен на увеличение конверсии.
```

## Практический вывод
Авторская логика решения задачи:
1. я знаю техническую часть
2. я знаю, как бы я решила задачу сама
3. я переложила свой рабочий процесс из головы на нейронку простыми запросами

## Где это особенно полезно
Подходит для:
- маркетинга
- копирайтинга
- аудита лендингов
- упаковки услуг
- делегирования повторяемых экспертных задач в ИИ

## Быстрый шаблон переноса задачи в ИИ
```text
Задача: [что нужно получить]
Контекст: [что за продукт, кто ЦА, зачем нужен результат]
Мой процесс решения:
1. [как я обычно начинаю]
2. [что проверяю дальше]
3. [по каким критериям принимаю решение]
4. [какой результат считаю хорошим]

Сначала проанализируй мой процесс, потом выполни задачу по шагам.
```

## Примечания
Сильная сторона материала — не магические формулы, а правильная последовательность внедрения ИИ в работу.

Это не просто набор промптов, а схема:
техника → процесс → делегирование.
