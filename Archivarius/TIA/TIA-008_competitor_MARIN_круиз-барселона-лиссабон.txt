## РАЗБОР

### Блок 1 - Крючок
**Текст:** "Ребята, я сейчас ругаться буду. Ну или искренне недоумевать..."

Механика: псевдоконфликтный крючок. Обещает скандал — даёт хорошую цену. Обманутое ожидание работает.

Работает: да, нестандартно для продающего поста. Большинство конкурентов начинают с "Горящее предложение!" — этот начинает с эмоции.

Слабость: "ругаться / недоумевать" — два глагола, две эмоции. Размывают удар.

### Блок 2 - Структура
Классическая воронка: эмоция → цена → сравнение с альтернативой → детали маршрута → состав включённого → CTA.

Маршрут расписан детально — каждый порт с деталью. Это сильно.

Слабое место: переход от эмоции к маршруту резкий. "На чём гуляем?" — слабый мост.

### Блок 3 - Язык

Живые находки:
- "360 евро с человека за неделю. В ИЮЛЕ!" — капслок в нужном месте, усиливает парадокс
- "Найти приличный отель за такие деньги нереально, а тут целое путешествие" — сравнение с альтернативой как якорь ценности
- "стоим аж до полуночи" — разговорное "аж" создаёт живость
- Деталь по каждому порту (Альгамбра, обезьяны Гибралтара) — конкретика превращает список в маршрут
- "каюты с окном стоят всего на 14€ дороже" — микро-апсейл встроен органично

Мёртвые зоны:
- "просто сказка" — клише, обесценивает сильный маршрут
- "классной американской компании" — оценка без аргумента
- "Забирайте, пока лавочку не закрыли" — дежурная срочность без конкретики
- Эмодзи перегружены: 5 штук, два одинаковых подряд

### Блок 4 - Конверсионная механика
Якорная цифра 360€ — в первом экране, после эмоционального разгона. Правильно.

Сравнение с альтернативой — сильный приём обоснования цены через контраст.

Микро-апсейл (каюта с окном +14€) — профессиональный ход.

CTA: ссылка на Telegram без объяснения что там делать. Слабо.

### Блок 5 - Аудиторная реакция
Высокий потенциал конверсии у тех кто уже думал о круизе. Маршрут убеждает сильнее чем эмоция крючка.

## ДЛЯ СИМБЫ

**+ Адаптировать:**

1. Псевдоконфликтный крючок
   Начать с эмоции которая обещает скандал — дать хорошую новость. Обманутое ожидание удерживает.
   Применимость:
   - Arno — флэш-продажи, горящие туры
   - Marin — неожиданно низкая цена на круиз
   - Лео (#СЛеоПоМиру) — личное удивление как крючок
   Не использовать: Sana, Luna — конфликт снижает доверие

2. Сравнение с альтернативой как якорь ценности
   "За эти деньги найти отель нереально — а тут целое путешествие." Цена обосновывается через контраст с более дорогой альтернативой.
   Применимость:
   - Все голоса Симбы — универсальный приём обоснования цены
   - Особенно: Arno, Marin

3. Деталь по каждому порту/объекту маршрута
   Не просто список мест — каждое место с одной конкретной деталью ("родина паэльи", "аж до полуночи").
   Применимость:
   - Marin — маршрут круиза
   - Luna — маршрут тура по дням
   - Лео — личные наблюдения из поездки

4. Органичный микро-апсейл
   Апгрейд встроен в описание как деталь. "Каюта с окном — всего на 14€ дороже."
   Применимость:
   - Marin — каюты, палубы
   - Luna — категории отелей
   - Sana — уровень процедур

**✕ Антипримеры:**

1. Двойной глагол в крючке
   "Ругаться / недоумевать" — две эмоции размывают удар.
   Симба не делает: давать читателю выбор между двумя реакциями в первой строке

2. Дежурная срочность без аргумента
   "Забирайте, пока лавочку не закрыли" — без дедлайна и количества мест не работает.
   Симба не делает: срочность без конкретики (дата, количество мест)

3. Оценка без аргумента
   "Классной американской компании" — читатель не знает почему классной.
   Симба не делает: давать оценку без одного конкретного факта-обоснования

4. CTA без инструкции
   Ссылка без объяснения что делать дальше.
   Симба не делает: давать ссылку без "напишите / позвоните / перейдите чтобы..."

**- Стоп-лист Critic C6:**
- просто_сказка — клише, обесценивает сильный контент после
- оценка_без_факта — "классный/отличный" без аргумента
- emoji_overload — более трёх эмодзи в посте, два одинаковых подряд

**~ Шаблон:**
- Сравнение с альтернативой обязательно при обосновании цены: не "дёшево", а "дешевле чем X при большей ценности"
- Микро-апсейл встраивается в описание как деталь, не выносится отдельным блоком
- CTA всегда с инструкцией: не "вот ссылка", а "напишите / позвоните / перейдите чтобы..."
