# TIA-010 | Анализ чужого текста
**Алгоритм:** TIA v1.0
**Дата:** 20.06.2026
**Метка:** [organic]
**Тема:** Личный тревел-отчёт / Грузия / Тбилиси + Кахетия
**Источник:** Facebook, русскоязычная аудитория Израиля, мужчина, личный блог
**Engagement:** 147 лайков / 59 комментариев

---

## РАЗБОР

### Блок 1 - Крючок
**Текст:** "Спойлер: этот графРоманский отчет про наш отдых в Грузии вам читать не обязательно."

Механика: антикрючок. "Не читайте" — читатель читает. "ГрафРоманский" — авторский неологизм, сигнал оригинального голоса.

Работает: да, сильно. 147 лайков при длинном тексте — доказательство.

### Блок 2 - Структура
Эпизодический дневник — серия сцен разделённых ***. Каждая сцена самодостаточна: начало, конец, внутренняя драматургия. Читатель может остановиться на любой сцене и не потерять нить.

Длинный текст читается легко потому что он не монолит — россыпь коротких историй.

### Блок 3 - Язык

Живые находки:
- "город с одного ракурса напоминал спрута, с другого чурчхелу, с третьего тарелку хумуса припорошенного паприкой" — тройная метафора нарастающей абсурдности
- "атмосферу белогвардейского шабаша" — три слова рисуют полную картину
- "смахивал пот со лба в квеври и терпеливо ждал пока мы засмеемся" — кинематографичная деталь убивает наповал
- "Где-то в Пекине сейчас крутят хит-рилс со мной" — неожиданный выход в настоящее время
- "Абзац про тамаду сильно сокращен по настоятельной просьбе Жены" — мета-комментарий как отдельная сцена
- "адвокаты умеют врать лучше тамадов" — афоризм-якорь
- "назло холестеринам" — одна фраза заменяет абзац объяснений
- Диалог с водителем — характер через прямую речь без авторских оценок

Мёртвые зоны:
- "очень вкусным местным пивом" — размытое прилагательное внутри текста с высоким уровнем конкретики

### Блок 4 - Конверсионная механика
Цель — читаемость и личный бренд. 147 лайков без CTA — конвертация в лояльность.

### Блок 5 - Аудиторная реакция
**Данные:** 147 лайков / 59 комментариев.

Соотношение 2.5:1 — люди читают до конца, тема не провоцирует спор. Это пост про который говорят "отлично написано", не "я не согласен".

Почему сработало: эпизодическая структура + юмор + конкретные цифры + диалоги + самоирония.

## ДЛЯ СИМБЫ

**+ Адаптировать:**

1. Антикрючок
   "Вам читать необязательно" — запретный плод. Работает только при высоком уровне текста.
   Применимость:
   - Лео (#СЛеоПоМиру) — длинные личные отчёты
   - Leona — посты с большим объёмом информации
   Не использовать: продающие посты Симбы — нельзя давать разрешение не читать

2. Эпизодическая структура с разделителями
   Серия самодостаточных сцен разделённых ***. Длинный текст воспринимается как короткий.
   Применимость:
   - Лео — длинные тревел-отчёты
   - Leona — многотемные посты
   Не использовать: Arno, Marin, Sana, Luna — там нужна единая воронка

3. Тройная нарастающая метафора
   Каждый следующий образ неожиданнее предыдущего. Последний — самый абсурдный.
   Применимость:
   - Лео, Leona — описание места или впечатления
   - Luna — крючок при описании направления

4. Характер через диалог без авторской оценки
   Не "водитель был болтливым" — а показываешь его через прямую речь.
   Применимость:
   - Лео — истории из поездок
   - Leona — клиентские истории
   Не использовать: Arno, Marin, Sana, Luna

5. Мета-комментарий как отдельная сцена
   Выход за четвёртую стену создаёт эффект живого разговора.
   Применимость:
   - Лео — фирменный приём голоса
   - Leona — для ощущения "своего человека"

6. Конкретная цифра как точка юмора
   "Заказал третью порцию назло холестеринам." Цифра + абсурдный повод = смех.
   Применимость:
   - Лео, Leona — в любом посте с едой или расходами

**✕ Антипримеры:**

1. Оценочное прилагательное внутри конкретного текста
   "Очень вкусным пивом" при высоком уровне детали — выбивает читателя.
   Симба не делает: снижать уровень конкретики внутри поста — держать планку до конца

2. Антикрючок без уровня текста
   "Необязательно читать" работает только если текст действительно стоит прочесть.
   Симба не делает: использовать антикрючок для слабого контента

**- Стоп-лист Critic C6:**
- оценка_среди_конкретики — "очень вкусный / очень красивый" внутри текста с высоким уровнем детали — заменять на конкретику или убирать

**~ Шаблон:**
- Эпизодическая структура для длинных постов Лео: серия сцен с *** вместо монолитного текста
- Характер через диалог: показывать человека через слова, не через авторскую оценку
- Антикрючок работает только при высоком уровне текста
