# TIA-009 | Анализ чужого текста
**Алгоритм:** TIA v1.0
**Дата:** 20.06.2026
**Метка:** [organic]
**Тема:** Личный бюджет / деньги как тема-табу / Тель-Авив
**Источник:** Facebook, русскоязычная аудитория Израиля, женщина, личный пост
**Engagement:** 65 лайков / 70 комментариев за 3 часа

---

## РАЗБОР

### Блок 1 - Крючок
**Текст:** "Суббота и почему бы не поговорить о деньгах."

Механика: приглашение в разговор через день недели + тему-табу. "Почему бы не" снимает официальность, создаёт ощущение случайного разговора.

Работает: да, мягко. Соответствует тону поста — бытовой, без претензий.

### Блок 2 - Структура
Три блока:
- Личная ситуация с конкретикой (аренда, квартира, окна)
- Бюджет по статьям
- Финальный вопрос к аудитории

Деталь про окна ("терпеть не могу эти малюсенькие окошечки") — неожиданное отступление которое оживляет сухую тему денег.

Слабое место: блок бюджета без цифр по каждой статье и без итога. "Поездки 6-9 раз в год" без стоимости — информация наполовину.

### Блок 3 - Язык

Живые находки:
- "терпеть не могу эти малюсенькие окошечки, да еще и жалюзи на них" — эмоциональная конкретика про быт, читатель мгновенно видит картинку
- "Света и солнца должно быть много" — ценность через требование, не через описание
- "Вот я прикинула и поняла" — разговорная интонация, снижает дистанцию
- "Коты — примерно 1000 в месяц" — неожиданная строка в бюджете, создаёт улыбку

Мёртвые зоны:
- "вполне бюджетно" — субъективная оценка без контекста
- "совсем мало" на салон красоты — непрозрачная цифра снижает доверие к остальным данным
- Финальный вопрос слишком широкий — работает только потому что тема горячая

### Блок 4 - Конверсионная механика
Цель — engagement через тему-табу. 70 комментариев за 3 часа подтверждают: работает.

Механика успеха: деньги + личная конкретика + прямой вопрос = комментарии. Люди либо соглашаются либо спорят с цифрой.

### Блок 5 - Аудиторная реакция
**Данные:** 65 лайков / 70 комментариев за 3 часа — высокий engagement.

Почему сработало:
- Тема денег универсальная и табуированная — притягивает
- Конкретные цифры провоцируют сравнение
- Коты как неожиданная строка разряжают напряжение
- Прямой вопрос даёт разрешение ответить

## ДЛЯ СИМБЫ

**+ Адаптировать:**

1. Тема-табу как движок engagement
   Деньги, цены, "сколько стоит" — триггерные темы которые автоматически генерируют комментарии.
   Применимость:
   - Лео (#СЛеоПоМиру) — "сколько я потратил в Баку за 4 дня"
   - Leona — "давайте честно про цены"
   - Любой пост Симбы с якорной ценой
   Не использовать: Sana, Marin — другая эмоциональная температура

2. Неожиданная деталь в списке как разрядка
   "Коты — примерно 1000 в месяц" — одна нестандартная строка снимает напряжение и создаёт человечность.
   Применимость:
   - Лео, Leona — в любом списке из 4+ пунктов
   - Luna, Sana — в блоке "что включено" для оживления

3. Ценность через требование, не через описание
   "Света и солнца должно быть много" вместо "мне нравится светлое жильё". Требование сильнее описания.
   Применимость:
   - Все голоса — при описании условий тура/отеля
   - Особенно: Sana ("тишина должна быть настоящей"), Luna ("море должно быть видно из окна")

4. Прямой вопрос о деньгах в финале
   Работает когда автор первым раскрыл свои цифры.
   Применимость:
   - Лео, Leona — после поста с личными тратами на поездку
   Не использовать: продающие посты Симбы

**✕ Антипримеры:**

1. Субъективная оценка без контекста
   "Вполне бюджетно" — для кого? Без сравнения с рынком оценка висит в воздухе.
   Симба не делает: давать оценку цены без контрольной точки сравнения

2. Непрозрачная цифра снижает доверие ко всем остальным
   "Совсем мало" — одна размытая цифра ставит под сомнение весь список.
   Симба не делает: смешивать конкретные цифры с размытыми оценками в одном списке

3. Широкий финальный вопрос без фокуса
   "А вы сколько тратите?" работает здесь только потому что тема горячая. В посте про тур — провалится.
   Симба не делает: рассчитывать что тема сама вытянет engagement без точного вопроса

**- Стоп-лист Critic C6:**
- субъективная_оценка — "вполне бюджетно / совсем недорого / немного" без цифры — убирать или конкретизировать

**~ Шаблон:**
- Неожиданная деталь в списке: одна нестандартная строка на любой список из 4+ пунктов
- Ценность через требование: "X должен быть Y" вместо "мне нравится когда X"
- Прямой вопрос о деньгах работает только если автор первым открыл свои цифры
