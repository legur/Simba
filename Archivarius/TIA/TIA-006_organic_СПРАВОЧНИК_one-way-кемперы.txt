# TIA-006 | Анализ чужого текста
**Алгоритм:** TIA v1.0
**Дата:** 19.06.2026
**Метка:** [organic]
**Тема:** Справочный пост / One Way аренда кемперов / подборка сервисов
**Источник:** Facebook, русскоязычная аудитория, travel-эксперт, формат полезного справочника

---

## РАЗБОР

### Блок 1 - Крючок
**Текст:** "Я обещала рассказать про всевозможные варианты One Way аренды кемперов"

Механика: обещание выполнено — крючок через доверие и ожидание. Работает только для лояльной аудитории, холодного читателя не зацепит.

Работает: частично — только на тёплой аудитории.

### Блок 2 - Структура
Три блока чётко разделены:
- Зачем (буллеты с выгодами)
- Что именно (5 сервисов с данными)
- Дисклеймер (читайте условия)

Структура справочника — логичная и функциональная. Не для вовлечения, для использования. Читатель сохраняет пост, не лайкает.

### Блок 3 - Язык
Живые находки:
- "он таки на любителей" — живая разговорная интонация внутри экспертного контента
- "можно приткнуть на 8-10 часов машину" — просторечие работает, создаёт образ без лишних слов
- Табличная структура каждого сервиса (что/где/цена/условия) — сканируется без чтения

Клише: нет. Утилитарный текст — клише здесь не живут.

### Блок 4 - Конверсионная механика
Цель поста — сохранение и репост, не продажа. Достигается через конкретику: цифры ($1/день, €129 за всё), условия, ссылки. CTA отсутствует — правильно для жанра. Дисклеймер в финале снижает риск претензий.

### Блок 5 - Аудиторная реакция
Высокий потенциал сохранений. Комментарии: "не знала что так можно", вопросы про маршруты, личный опыт. Вирусность низкая — нишевый контент.

---

## ДЛЯ СИМБЫ

**+ Адаптировать:**

1. Справочный формат с табличной структурой
   Каждый объект по одной схеме: что / где / цена / условия. Читатель сканирует, не читает.
   Применимость:
   - Лео (#СЛеоПоМиру) — сравнение туров, подборки направлений
   - Leona — форматы "5 причин / 5 вариантов"
   Не использовать: продающие посты Симбы — там нужен нарратив, не таблица

2. Разговорное просторечие внутри экспертного контента
   "Таки на любителей", "приткнуть машину" — снижает официальность не теряя экспертности
   Применимость:
   - Лео — фирменный приём голоса
   - Leona — для аудитории 45+ работает как "свой человек говорит"
   Не использовать: Arno, Marin, Sana, Luna — другая температура

3. Дисклеймер как защита репутации
   "Внимательно читайте условия" в финале подборки с внешними ссылками
   Применимость:
   - Любой пост Симбы/Лео с конкретными ценами и условиями операторов
   - Обязательно когда даются ссылки на третьи сервисы

**- Стоп-лист Critic C6:**
- weak_hook_announce — "я обещала рассказать про X" как крючок. Работает только на лояльной аудитории, для холодного читателя — провал

**~ Шаблон:**
- Справочный пост: структура каждого объекта одинаковая. Читатель должен уметь сканировать без чтения
- Дисклеймер обязателен в постах с внешними ценами и ссылками
