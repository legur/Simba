## Описание
Подбор экспертных тем для контент-плана, которые укрепят авторитет компании в индустрии.

## Раздел
4. Руководство

## Prompt (русский)
Составь список из четырех актуальных и интересных идей для постов в блоге от лица экспертов для [компания] на основе популярных тем, анализа целевой аудитории и ключевых слов бренда.


## Prompt (original)
Generate a list of four relevant and engaging thought leadership blog post ideas for [company] based on trending topics, target audience analysis, and brand keywords.


## Примеры использования
Контент-план для соцсетей, темы для гостевых статей, идеи для корпоративного блога.

Импортировано из Excel-таблицы с промтами.
