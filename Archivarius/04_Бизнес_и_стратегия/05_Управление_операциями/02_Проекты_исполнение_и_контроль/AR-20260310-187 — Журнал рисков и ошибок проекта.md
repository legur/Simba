## Описание
Формирует структуру для логирования и контроля рисков или ошибок в ходе работы.

## Раздел
5. Управление проектами

## Prompt (русский)
Создайте таблицу для отслеживания проблем проекта, включая описания, статус, назначенного владельца и действия по их решению.


## Prompt (original)
Create a spreadsheet to track project issues, including descriptions, status, assigned owner, and action items for resolution.


## Примеры использования
Баг-трекинг в IT-проекте, журнал дефектов на стройке, список жалоб клиентов, реестр операционных рисков.
