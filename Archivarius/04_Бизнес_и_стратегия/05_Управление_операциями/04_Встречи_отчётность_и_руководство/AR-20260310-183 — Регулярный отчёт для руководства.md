## Описание
Готовит структуру регулярного отчета для руководства, чтобы показать прогресс и планы.

## Раздел
5. Управление проектами

## Prompt (русский)
Составьте шаблон электронного письма с отчетом о статусе проекта для отправки моему менеджеру. Включите разделы для краткого изложения ключевых достижений за эту неделю, возникших проблем и трех приоритетных задач на следующую неделю.


## Prompt (original)
Draft a project status update email template to send to my manager. Include sections for a summary of key accomplishments this week, any challenges faced, and the top three priorities for next week.


## Примеры использования
Еженедельный отчет по маркетингу, апдейт по разработке ПО, сводка по продажам за месяц, отчет для инвесторов.


## Notes
Импортировано из Excel-таблицы с промтами.
