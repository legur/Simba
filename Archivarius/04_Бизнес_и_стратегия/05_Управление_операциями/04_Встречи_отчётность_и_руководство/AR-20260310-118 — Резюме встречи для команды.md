## Описание
Быстро составить вдохновляющее резюме встречи для команды на основе файла с заметками.

## Раздел
2. Стартапы

## Prompt (русский)
Используй @[Заметки и идеи мозгового штурма 01.09.24], чтобы написать итоги встречи для [команды] в бодром и дружелюбном тоне. Поделись некоторыми идеями, которые у меня есть для нашей следующей встречи для обсуждения [темы].


## Prompt (original)
Use @[Brainstorm Notes and Ideas 9/1/24] to write a meeting recap to [the team] using an upbeat and friendly tone. Share some of the ideas I have for our next meeting to discuss [topic].


## Примеры использования
Рассылка по итогам митинга, фиксация договоренностей, мотивация сотрудников.


## Notes
Импортировано из Excel-таблицы с промтами.
