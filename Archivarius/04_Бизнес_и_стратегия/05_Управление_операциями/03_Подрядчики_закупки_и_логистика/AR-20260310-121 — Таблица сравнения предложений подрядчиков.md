## Описание
Сопоставить условия разных подрядчиков в наглядной таблице для выбора лучшего варианта.

## Раздел
2. Стартапы

## Prompt (русский)
Мне нужно принять решение о выборе поставщика для производства упаковки. Создай таблицу, сравнивающую два предложения, которые я получил: @[Предложение компании А] и @[Предложение компании Б].


## Prompt (original)
I need to make a vendor decision for packaging manufacturing. Create a table that compares the two proposals I've received @[Company A’s Proposal] and @[Company B’s Proposal].


## Примеры использования
Выбор IT-разработчиков, сравнение условий аренды, закупка материалов.


## Notes
Импортировано из Excel-таблицы с промтами.
