## Описание
Настройка системы учета корпоративного софта для контроля сроков оплаты и прав доступа.

## Раздел
4. Руководство

## Prompt (русский)
Создай таблицу для отслеживания лицензий на программное обеспечение для сотрудников и добавь колонки для типов лицензий, прав на использование и дат продления.


## Prompt (original)
Create a tracker of software licenses for employees and include columns for license types, usage rights, and renewal dates.


## Примеры использования
Инвентаризация ПО в офисе, контроль подписок команды, учет доступов к сервисам.
