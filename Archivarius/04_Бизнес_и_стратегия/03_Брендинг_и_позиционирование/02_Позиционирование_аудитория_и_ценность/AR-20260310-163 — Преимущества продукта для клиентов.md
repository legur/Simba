## Описание
Формирование преимуществ продукта для клиентов с учетом опыта прошлых рекламных запусков.

## Раздел
4. Руководство

## Prompt (русский)
Придумай ценностные предложения для моей [целевой аудитории] на основе функций из @[Требования к продукту]. Добавь раздел с выводами по кампаниям из @[Эффективность кампаний].


## Prompt (original)
Brainstorm value props for my [target audiences] based on features from @[Product Requirements Document]. Include a section on campaign learnings from @[Campaign Performance].


## Примеры использования
УТП для лендинга, идеи для рекламных креативов, презентация продукта для партнеров.
