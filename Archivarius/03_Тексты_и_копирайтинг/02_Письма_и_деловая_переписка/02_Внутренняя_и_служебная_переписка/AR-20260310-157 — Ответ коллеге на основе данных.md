## Описание
Подготовка аргументированного ответа коллеге на основе данных из конкретного рабочего файла.

## Раздел
4. Руководство

## Prompt (русский)
Создай ответ для [человека] по теме [тема]. Включи подробности о [результате] и [сроках], используя @[Отчет о состоянии проекта А].


## Prompt (original)
Generate a response to [person] about [topic]. Include details on [deliverable] and [timeline] using @[Project A Status Report].


## Примеры использования
Ответ клиенту по проекту, апдейт статуса для босса, уточнение сроков поставки.


## Notes
Импортировано из Excel-таблицы с промтами.
