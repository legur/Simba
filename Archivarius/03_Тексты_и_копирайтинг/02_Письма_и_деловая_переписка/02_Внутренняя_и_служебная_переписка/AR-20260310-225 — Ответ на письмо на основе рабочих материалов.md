## Описание
Пишет готовый ответ на почту, опираясь на информацию из ваших рабочих файлов.

## Раздел
7. Администратор

## Prompt (русский)
Напиши ответ на это письмо, используя данные из файла @[название], чтобы объяснить связь проектов.


## Prompt (original)
Generate a response to this email and use @[file name] to describe how the [initiative] can complement the workstream.


## Примеры использования
Ответ клиенту по прайсу, письмо коллеге по проекту, деловое предложение.
