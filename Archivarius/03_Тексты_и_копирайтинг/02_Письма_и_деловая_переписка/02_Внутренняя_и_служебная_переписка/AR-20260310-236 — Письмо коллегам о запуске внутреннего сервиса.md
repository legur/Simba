## Описание
Составить позитивное письмо для коллег о запуске внутреннего сервиса. Объясняет пользу обновлений, опираясь на пожелания коллектива.

## Раздел
8. Коммуникация

## Prompt (русский)
Мне нужно подготовить служебную записку для всей компании об обновлении нашего внутреннего портала. [Новая страница] решает [частые жалобы сотрудников] и делает работу удобнее. Напиши бодрое объявление о [новом сайте], используя @[Intranet Launch Plan Notes].


## Prompt (original)
I need to draft a company-wide memo unveiling our relaunched intranet. The [new page] addresses [common feedback we heard from employees] and aims to create a more user friendly experience. Draft an upbeat memo announcing [the new site] using @[Intranet Launch Plan Notes].


## Примеры использования
Анонс новой системы премий, письмо о переезде в новый офис, новость о внедрении CRM, сообщение о корпоративном празднике.
