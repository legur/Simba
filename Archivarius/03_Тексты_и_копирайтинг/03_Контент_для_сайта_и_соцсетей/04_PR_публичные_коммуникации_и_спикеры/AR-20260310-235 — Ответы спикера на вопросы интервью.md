## Описание
Написать убедительные ответы на вопросы интервью, используя факты о продукте. Текст создается сразу в нужном стиле от лица конкретного руководителя.

## Раздел
8. Коммуникация

## Prompt (русский)
Используй @[Product Launch Notes], чтобы написать варианты ответов на эти вопросы. Сформулируй тезисы от лица [должность спикера] в [компания].


## Prompt (original)
Use @[Product Launch Notes] to write suggested answers for these questions. Write the talking points as if you are [title of spokesperson] at [company].


## Примеры использования
Шпаргалка для выступления на радио, ответы для письменного интервью, тезисы для FAQ на сайте, подготовка комментариев для прессы.


## Notes
Импортировано из Excel-таблицы с промтами.
