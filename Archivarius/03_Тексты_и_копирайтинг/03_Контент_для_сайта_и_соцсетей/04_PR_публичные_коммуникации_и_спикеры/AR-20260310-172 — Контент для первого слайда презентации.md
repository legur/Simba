## Описание
Создание контента для первого слайда презентации на основе ранее подготовленных рабочих материалов.

## Раздел
4. Руководство

## Prompt (русский)
Мне нужно создать презентацию, чтобы объяснить техническую тему нетехнической аудитории. Создай [вступительный слайд], который [описывает, что такое генеративный ИИ], используя @[Заметки с объяснением генеративного ИИ].


## Prompt (original)
I need to build a presentation to explain a technical topic to a non-technical audience. Generate an [introduction slide] that [describes what generative AI is] using @[Gen AI Explanation Notes].


## Примеры использования
Обучающая презентация для коллег, вводная лекция для клиентов, слайд для отчета.


## Notes
Импортировано из Excel-таблицы с промтами.
