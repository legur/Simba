## Описание
Сделать основу для пресс-релиза по результатам покупки новой компании. Помогает быстро собрать ключевые тезисы и цитаты руководства в один текст.

## Раздел
8. Коммуникация

## Prompt (русский)
Я PR-менеджер. Мне нужно создать пресс-релиз с броским заголовком. Включи цитаты из файла @[VIP Quotes Acquisition].


## Prompt (original)
I’m a PR manager. I need to create a press release with a catchy title. Include quotes from @[VIP Quotes Acquisition].


## Примеры использования
Слияние компаний, запуск новой линейки товаров, анонс крупного партнерства, отчет о благотворительной акции.
