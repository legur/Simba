## Описание
Подготовить информативный слайд для презентации по рабочим заметкам. ИИ адаптирует техническую информацию под обычного слушателя.

## Раздел
8. Коммуникация

## Prompt (русский)
Создай слайд с описанием продукта [product] на основе @[Product Launch - Notes]. Сделай его коротким и понятным для широкой аудитории.


## Prompt (original)
Create a slide describing what [product] is from @[Product Launch - Notes]. Make sure it is short and easily understood by a broad audience.


## Примеры использования
Презентация стартапа инвесторам, слайд для внутреннего обучения сотрудников, визуализация преимуществ товара, презентация проекта на грант.


## Notes
Импортировано из Excel-таблицы с промтами.
