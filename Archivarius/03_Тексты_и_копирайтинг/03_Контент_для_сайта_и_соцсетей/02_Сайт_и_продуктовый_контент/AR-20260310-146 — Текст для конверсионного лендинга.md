## Описание
Написать текст для сайта-одностраничника, который убедит начальников скачать книгу или записаться на вебинар.

## Раздел
3. Отдел маркетинга

## Prompt (русский)
Создай убедительный текст для целевой страницы, продвигающей новый [электронная книга/вебинар/бесплатная пробная версия и детали], предназначенный для руководящей целевой аудитории. Выдели основные преимущества и стимулируй конверсии с помощью убедительных призывов к действию.


## Prompt (original)
Create compelling copy for a landing page promoting a new [ebook/webinar/free trial and details] designed for an executive target audience. Highlight key benefits and encourage conversions with persuasive calls to action.


## Примеры использования
Копирайтинг для лендингов, Продающая страница, Оформление лид-магнита, Текст для регистрации
