# AR-20260128-044 - Иммерсивная реальность + овощ в стиле кунг-фу

## Коротко
Промпт для генерации забавных "героев" в иммерсивной реальности.
Базовый объект - простой овощ.
Можно заменить овощ на любой предмет.

## Где использовать
- Nano Banana Pro (image generation)
- Любые модели, которые хорошо держат позу и стиль (Shedevrum / Seedream / Wan / Midjourney)

## Вход
- Текстовый промпт
- (Опционально) Добавьте уточнение объекта: "carrot" / "cucumber" / "rubber duck" / "wrench" и т.д.

## Выход
- 1 изображение (рекомендую 1:1 или 4:5)
- Без текста и логотипов

## Порядок исполнения
1. Откройте VeoSeeBot или сайт
2. Выберите "Работа с изображениями" -> Nano Banana Pro
3. Вставьте PROMPT ниже
4. Замените "simple vegetable object" на нужный объект (по желанию)
5. Сгенерируйте 4 варианта и выберите самый читаемый по позе

## PROMPT (EN)
immersive reality, simple vegetable object, kung fu style pose, funky funny histerically

## Быстрые модификации
- Сменить объект:
  - "simple vegetable object" -> "a single carrot" / "a single eggplant" / "a peeled banana" / "a vintage camera" / "a chrome wrench"
- Уточнить стиль:
  - add: "cinematic lighting, shallow depth of field, crisp details"
- Убрать VR-артефакты (если модель путается):
  - replace "immersive reality" -> "cinematic scene" or "surreal studio scene"
