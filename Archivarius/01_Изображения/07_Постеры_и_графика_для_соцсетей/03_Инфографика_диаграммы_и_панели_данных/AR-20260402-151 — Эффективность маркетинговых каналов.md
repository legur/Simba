# Определить наиболее эффективные маркетинговые каналы

## Prompt

```text
Проанализируй эту таблицу с данными о маркетинговой эффективности и определи, какие каналы показали наивысший ROI. Файл включает данные кампаний за 1-й и 2-й кварталы по каналам: email, социальные сети, платный поиск и мероприятия. Составь сводку по топ-3 каналам и создай диаграмму, показывающую ROI по каждому каналу.
```
