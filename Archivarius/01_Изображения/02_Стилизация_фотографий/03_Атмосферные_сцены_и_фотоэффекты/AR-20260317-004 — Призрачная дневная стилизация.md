## Пост
Стилизация человека с референсного фото в полупрозрачный призрачный образ: холодный контурный свет, эфемерная ткань, мягкие формы и темная пустота на фоне.

## Инструкция
1. Открой генератор с поддержкой image-to-image.
2. Загрузи reference photo человека.
3. Вставь основной промпт ниже.
4. При необходимости добавь позу, предмет в руках или детали сцены в конец запроса.
5. Если модель уводит результат в лишнюю откровенность, усили ограничение `no explicit nudity, elegant, non-sexual, atmospheric`.

## Промпт
```text
Using the uploaded reference photo as the ONLY face and body reference, create a translucent ghostly figure with clearly recognizable facial features and silhouette from the reference image. Ethereal, semi-transparent appearance, cold rim lighting, flowing ghost-like fabric, soft contours, dark void background. Keep the character elegant, mysterious, and atmospheric, with no explicit nudity. The person should look like a spectral version of the uploaded subject, preserving identity while transforming them into a haunting, dreamlike ghost. Cinematic mood, minimal composition, subtle motion in the fabric, high detail, soft supernatural glow.
```
