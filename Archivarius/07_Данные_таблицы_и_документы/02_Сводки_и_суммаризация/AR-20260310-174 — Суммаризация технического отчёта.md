## Описание
Быстрое выделение самого важного из длинного технического отчета для конкретной группы лиц.

## Раздел
4. Руководство

## Prompt (русский)
Сформулируй основные выводы и последствия этого отчета для [аудитория]. Сосредоточься на основных выявленных [уязвимостях] и рекомендуемых действиях по их устранению. Используй официальный стиль.


## Prompt (original)
Summarize the key findings and implications of this report for [audience]. Focus on the main [vulnerabilities] identified and the recommended actions to address them. Use a formal tone.


## Примеры использования
Резюме для ИТ-директора, выводы по аудиту безопасности, краткая выжимка из ТЗ.

Импортировано из Excel-таблицы с промтами.
