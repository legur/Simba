## Описание
Собрать важные данные о товаре из разных документов в один краткий текст. Это позволяет быстро ответить на сложные вопросы покупателя.

## Раздел
9. Служба поддержки

## Prompt (русский)
Составь краткую справку о [название продукта], включая правила возврата, состав и сертификаты.


## Prompt (original)
Summarize information about [product name] including the product’s specific [return policy], [ingredients], and [certifications].


## Примеры использования
Карточка товара для оператора, справка для обучения новичков, описание для чат-бота, конспект для базы знаний.
