## Описание
Сделать удобную сетку для планирования выходов сотрудников на работу по сменам.

## Раздел
1. Малый бизнес

## Prompt (русский)
Создай таблицу для отслеживания еженедельного графика персонала. Сделай столбцы для даты, имени, смены (утро или вечер) и примечаний.


## Prompt (original)
Create a table that tracks weekly staffing. Create columns for date, name, shift (AM or PM), and notes.


## Примеры использования
Смены в магазине, график администраторов, дежурства техподдержки, выходы промоутеров.


## Notes
Импортировано из Excel-таблицы с промтами.
