## Описание
Сделать таблицу, чтобы следить за тем, где и когда публикуется ваша реклама и статьи.

## Раздел
3. Отдел маркетинга

## Prompt (русский)
Создай трекер проекта для продвижения контента и включи столбцы для канала, владельца, URL-адреса и уровня приоритета (низкий, средний, высокий).


## Prompt (original)
Create a project tracker for content amplification and include columns for channel, owner, URL, and priority level (low, medium, high).


## Примеры использования
Планирование посевов, Контент-план, Контроль дистрибуции, Отчет по продвижению
