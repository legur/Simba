## Описание
Переделывает обычный текст в удобную таблицу с четкой структурой.

## Раздел
7. Администратор

## Prompt (русский)
Сделай из этой программы таблицу и добавь по одной игре на каждый день.


## Prompt (original)
Organize this agenda in a table format. Include one of your suggested icebreakers for each day.


## Примеры использования
План работ, график смен, список задач, календарь встреч.


## Notes
Импортировано из Excel-таблицы с промтами.
