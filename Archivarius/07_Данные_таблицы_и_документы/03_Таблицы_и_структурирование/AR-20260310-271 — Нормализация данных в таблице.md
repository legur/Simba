## Описание
Почистить данные в таблице: заменить пустые имена, сократить названия офисов и убрать лишние строки.

## Раздел
11. Отдел кадров

## Prompt (русский)
Помоги мне привести в порядок таблицу с результатами опроса сотрудников. В частности, заполни все пустые значения в столбце с именами словом «Анонимно», а если в столбце с регионом указано «Штаб-квартира», замени это на «ШК». Наконец, удали все строки, где столбец с уровнем удовлетворенности пуст. Пожалуйста, создай для меня новый файл с очищенными данными.


## Prompt (original)
Help me clean my employee survey spreadsheet. Specifically, fill any blank values in the name column with "Anonymous," and if the region column shows Headquarters, replace that with HQ. Finally, remove any rows where the satisfaction column is blank. Please generate a new file for me with my cleaned data.


## Примеры использования
Обработка результатов опроса, Подготовка данных к анализу, Очистка Excel файлов, Подготовка отчета


## Notes
Импортировано из Excel-таблицы с промтами.
