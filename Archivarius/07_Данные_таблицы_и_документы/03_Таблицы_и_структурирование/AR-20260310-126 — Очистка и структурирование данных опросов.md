## Описание
Автоматически привести данные из опросов в порядок, убрав мусор и заполнив пробелы.

## Раздел
2. Стартапы

## Prompt (русский)
Помоги мне очистить таблицу опроса [отзывы пользователей]. В частности, заполни любые пустые значения в столбце имени словом "Аноним", затем, если в столбце [рекомендую] стоит [Да], замени это на [Д]. Наконец, удали все строки, где столбец удовлетворенности пуст. Пожалуйста, создай для меня новый файл с моими очищенными данными.


## Prompt (original)
Help me clean my [user feedback] survey spreadsheet. Specifically, fill any blank values in the name column with "Anonymous," then if the [recommend] column shows [Yes], replace that with [Y]. Finally, remove any rows where the satisfaction column is blank. Please generate a new file for me with my cleaned data.


## Примеры использования
Обработка результатов NPS-опроса, подготовка базы для аналитики, чистка CRM.


## Notes
Импортировано из Excel-таблицы с промтами.
