## Описание
Собрать список задач в таблицу, используя информацию из текстовой инструкции.

## Раздел
10. Фронт-офис

## Prompt (русский)
Я менеджер магазина, и мне нужно составить контрольный список моих обязанностей по открытию и закрытию смены. Создай шаблон с колонками для [обязанности по открытию и закрытию] на основе данных из @[Onboarding New Hire Information].


## Prompt (original)
I am a retail manager and I need to create a checklist for my opening and closing duties. Create a template with columns for [opening and closing duties] from @[Onboarding New Hire Information].


## Примеры использования
Чек-лист открытия магазина, План закрытия смены, Список ежедневных задач администратора, График уборки

Импортировано из Excel-таблицы с промтами.
