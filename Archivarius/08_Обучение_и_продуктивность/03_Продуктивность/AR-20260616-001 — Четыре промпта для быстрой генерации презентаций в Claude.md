## Пост
Подборка рабочих промптов для быстрой генерации презентаций в Claude. Промпты помогают собрать общий шаблон, структуру по слайдам, повествовательную логику и рекомендации по визуальному оформлению.

## Назначение
Пакет предназначен для ускорения подготовки презентационных материалов: от первичного брифа и логики слайдов до сторителлинга и дизайн-направления. Подходит для деловых, обучающих, маркетинговых и экспертных презентаций.

## Инструкция
1. Выбери нужный сценарий: общий шаблон, структура слайдов, сторителлинг или дизайн.
2. Замени `[тема]` на тему презентации.
3. При необходимости добавь контекст: аудитория, длительность выступления, формат мероприятия, цель, желаемое количество слайдов.
4. Для более точного результата можно запускать промпты последовательно: сначала шаблон, затем структура, затем сторителлинг, затем дизайн.

## Промпты

### Prompt 1. Шаблон презентации
```text
Веди себя как консультант по презентациям. Создай полный шаблон для [тема]: цель, аудитория, ключевое сообщение, структура и количество слайдов.
```

### Prompt 2. Структура по слайдам
```text
Разработай структуру презентации на тему [тема]. Дай названия слайдов и опиши цель каждого, чтобы обеспечить связный переход между частями.
```

### Prompt 3. Сторителлинг
```text
Преобразуй тему [тема] в презентацию с повествовательной логикой: зацепка → проблема → озарение → решение → вывод. Сохраняй деловой тон.
```

### Prompt 4. Рекомендации по дизайну
```text
Дай профессиональные советы по визуальному оформлению презентации на тему [тема]: подходящие макеты, диаграммы, схемы, иконки и другие элементы.
```

## Примечания
- Не является дублем `AR-20260326-003`: там универсальная формула сильного запроса, здесь — отдельный пакет для генерации презентаций.
- Связано с `AR-20260614-001`, потому что обе карточки помогают структурировать тему, но текущая карточка ориентирована именно на презентационный формат.
- Для сильного результата лучше добавлять к `[тема]` конкретику: аудитория, цель презентации, отрасль, уровень детализации, ограничение по времени и желаемое действие после просмотра.
- Если презентация нужна для продажи или туризма, стоит отдельно добавить требование: «не придумывай факты, цены, даты и подтверждения; пометь непроверенные данные».
