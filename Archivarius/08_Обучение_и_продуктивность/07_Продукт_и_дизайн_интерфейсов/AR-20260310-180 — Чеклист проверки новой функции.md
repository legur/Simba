## Описание
Составить список проверок, чтобы убедиться, что новая функция или форма работает правильно.

## Раздел
5. Управление проектами

## Prompt (русский)
Создайте таблицу с 10 пользовательскими приемочными тестами (UAT) для формы регистрации на сайте.


## Prompt (original)
Create a table with 10 user acceptance tests (UAT) for the website registration form.


## Примеры использования
Запуск личного кабинета, проверка корзины интернет-магазина, тестирование анкеты кандидата, аудит формы обратной связи.
