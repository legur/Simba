## Пост
Промт для быстрого объяснения любой темы на уровне пользователя: короткая суть, бытовая аналогия, скрытые тонкости, одно вредное заблуждение и вопрос для самопроверки.

## Инструкция
1. Подставь тему вместо `[тема]`.
2. Укажи реальный уровень подготовки.
3. Отправь промпт модели.
4. Если хочешь сильнее адаптировать ответ, замени уровень на конкретную роль: например, `я junior frontend`, `я CEO без технического бэкграунда`, `я школьник`, `я маркетолог`.

## Промпт
```text
Объясни [тема].

Мой уровень: знаю основы, но не эксперт.

Структура:
1. Суть - один абзац, без воды
2. Как это работает - аналогия из повседневной жизни
3. 3 тонкости, которые новички пропускают
4. 1 заблуждение, которое нужно забыть
5. Вопрос для самопроверки (с ответом под спойлером)
```

## Примечания
Усиленная версия с более четкой адаптацией под роль:

```text
Объясни [тема].

Мой уровень: [опиши свой реальный уровень или роль, например: junior frontend / CEO без технического бэкграунда / новичок в аналитике].

Сделай мини-урок без лекции и без воды.

Структура ответа:
1. Суть - один короткий абзац
2. Как это работает - одна простая аналогия из повседневной жизни
3. 3 тонкости, которые новички обычно упускают
4. 1 распространенное заблуждение, которое нужно забыть
5. 1 вопрос для самопроверки
6. Ответ на вопрос - отдельно, под спойлером или в самом конце

Пиши ясно, просто и на моем уровне.
```

Компактная версия:

```text
Объясни [тема] на моем уровне.

Мой уровень: [уровень].

Дай:
1. Суть
2. Простую аналогию
3. 3 тонкости
4. 1 заблуждение
5. Вопрос для самопроверки с ответом
```

Что можно адаптировать:
- заменить уровень на профессию или роль
- просить объяснение для ребенка, джуна, менеджера, основателя
- ограничить ответ по длине
- добавить пример из конкретной сферы
- просить не только аналогию, но и мини-кейс
