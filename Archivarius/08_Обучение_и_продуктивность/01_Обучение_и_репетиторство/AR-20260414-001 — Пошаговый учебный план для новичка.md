## Назначение
Промт для построения понятного плана обучения по любой новой теме. Хорошо подходит, когда тема большая, а вход в нее кажется хаотичным.

## Когда использовать
Подходит для:
- изучения новой темы с нуля
- подготовки личного плана обучения
- самостоятельного обучения без преподавателя
- разбиения сложной темы на понятные этапы
- подготовки мини-курса или roadmap

## Исходный промпт
```text
Ты — мой личный преподаватель по [ТЕМЕ]. Разбейте [ТЕМУ] на структурированный план обучения, которому может следовать новичок. Для каждого этапа включите: 1. Объяснение концепции простыми словами. 2. 1 практический пример. 3. 1 небольшое упражнение или тест для проверки понимания. 4. Распространённые ошибки, которых следует избегать. После выполнения всех шагов составьте краткую шпаргалку для быстрого повторения. Для наглядности разбейте ответ на пронумерованные этапы.
```

## S01 — семпл использования
```text
Ты — мой личный преподаватель по Excel для начинающих. Разбейте Excel для начинающих на структурированный план обучения, которому может следовать новичок. Для каждого этапа включите: 1. Объяснение концепции простыми словами. 2. 1 практический пример. 3. 1 небольшое упражнение или тест для проверки понимания. 4. Распространённые ошибки, которых следует избегать. После выполнения всех шагов составьте краткую шпаргалку для быстрого повторения. Для наглядности разбейте ответ на пронумерованные этапы.
```

## Практические заметки
Сильные стороны:
- сразу превращает тему в маршрут, а не в хаотичный поток информации
- совмещает объяснение, практику и самопроверку
- хорошо подходит новичкам
- в конце дает короткую шпаргалку для повторения

Риски:
- модель может сделать слишком общий план без глубины
- иногда шаги получаются неравномерными по сложности
- без указания уровня и цели тема может расползтись слишком широко

Рекомендации:
- лучше сразу уточнять уровень: новичок, средний, продвинутый
- полезно добавлять цель: для работы, экзамена, собеседования, хобби
- для прикладных тем можно просить больше упражнений на каждом шаге

## Мини-усиления
Если нужен более прикладной уклон:
```text
Сделай упор на практические навыки и реальные жизненные сценарии, а не на теорию ради теории.
```

Если нужен более короткий план:
```text
Ограничь план 5-7 этапами и оставь только самое важное.
```

Если нужна адаптация под взрослого ученика:
```text
Объясняй без инфантилизации, но простым языком и с ясной логикой.
```
