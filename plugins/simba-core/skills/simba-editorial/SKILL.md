# Simba CORE — редакционный пилот

Работает **только** после подключения локального MCP-сервера `simba-core` в ChatGPT Desktop. Сама установка навыка не означает, что сервер, API-ключ или автономные агенты подключены.

При запросе «продолжай аудит», «проверь работу Симбы», «сделай тест» сначала запусти `simba_core_preflight`. Сообщи фактически обнаруженные блокеры. Не интерпретируй чтение Markdown или успешные офлайн-тесты как работающих агентов.

**Бесплатный контроль передачи редакций:** если пользователь просит проверить цепочку на одном тексте, но не санкционировал API-расходы, после preflight вызови `simba_core_handoff_selftest` (пустые аргументы). Это синтетический тест состояний Simba → Critic → Simba repair → Critic → Simba finalize → Humanizer → Critic, с проверкой хешей и негативных блокеров. Отчет `OFFLINE_HANDOFF_CONTRACT_OK_NOT_AGENT_EXECUTION` доказывает только работоспособность локальной логики и **не** означает, что модели агентов действительно исполнялись.

**Текстовая цепочка:** по отдельному, одобренному пользователем бюджету может вызываться `simba_core_run_private_pilot`. Требуются сразу: `execute_live=true`, `permit_billable_api_calls=true`, `SIMBA_CORE_ALLOW_BILLABLE=1`, установленный вне чата API-ключ и приватная директория. Короткая команда «дальше» не означает разрешения на платные запросы. Модель и лимиты должны быть явными. Не пытайся обойти gates или повторять запрос с неизвестным исходом оплаты.

Если платный пилот действительно выполнен, проверь `simba_core_audit_pilot_receipts`, затем при необходимости прочитай текст через `simba_core_read_pilot_text`. Даже успешный пилот имеет статус `LIVE_EDITORIAL_PILOT_UNVERIFIED`; технический разбор JSON даёт только `DECLARED_RECEIPTS_CONSISTENT_AUTHENTICITY_UNVERIFIED`. Никакой из них **не равен** `TEXT_READY_FOR_LEO`, `APPROVED_TEXT` или `PUBLISHED`.

**Границы:** это внешние отдельные вызовы API, а не внутренняя ChatGPT-команда, которая самостоятельно создаёт три субагента. Для полного production-статуса также нужны источники и проверка фактов, TIA, реальные независимые receipts и решение Лео. Не модифицируй утвержденные тексты, архив и публичные Issues приватными данными. Не запускай Rafael, Киностудию, генерацию медиа или публикацию.

Если нет MCP-сервера, назови точный инфраструктурный блокер. Не симулируй вызов, не выдавай готовые посты от имени независимых ролей и не создавай фиктивные PASS.
