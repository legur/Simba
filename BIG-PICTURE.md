Обновлено 19.10.2026 в рамках подключения Zernio; это не полный аудит проекта.

- Канонические инструкции: legur/Simba, AGENTS → Router → Knowledge Map → Runtime Protocol.
- Подготовка постов: авторские проверки/Humanizer → утверждение текста → Rafael,

- Zernio: существующая CLI-авторизация; утверждённый пакет → явно выбранная Leo
  Facebook-страница → draft → независимое повторное чтение. Команды и ограничения:
  `integrations/ai_plugins/ZERNIO.md`.
- Повторы защищены локальными блокировками/журналом и remote metadata. При
  неизвестном исходе требуется сверка; атомарность между машинами CLI не предоставляет.
- Публикация/расписание требуют отдельной явной команды Leo для конкретного draft ID.
- Проверено: обе страницы доступны; offline-тесты, local dry-run и блокировка без
  страницы. Реальное создание draft/upload/readback не проверено: конкретные пакет
  и страница для smoke не выбраны. Публикация не выполнялась.
- Подробное evidence: `integrations/ai_plugins/VALIDATION.md`. Состояние отдельных
  контентных задач проверять по Content Library, не выводить из этой карты.
