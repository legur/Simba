## Быстрые действия

```bash
python3 integrations/materials/catalog.py resume Бавария
python3 integrations/materials/catalog.py resume Прага
python3 integrations/materials/catalog.py reuse Бавария --kind animated_clip
python3 integrations/materials/catalog.py search "титры" --library kadr
```

Без локального Python открыть запись проекта, затем актуальные `sources` и выбранные файлы через доступные GitHub/Drive-инструменты. Сверить последнюю правку Лео. Изменение источника делает прежнюю сводку потенциально устаревшей.

Поиск охватывает Архивариуса, TIA, Кадр, журналы Критика и библиотеку контента; [описание](../integrations/materials/README.md). Пригодность найденной карточки проверяется по правилам соответствующей роли.

После каждого завершенного этапа исполнитель обновляет существующий источник и ту же запись проекта, проверяет ссылки и сохранение. Автоматический обмен данными с другими чатами или Notion пока не настроен.


### Проверка реальных медиа — 17.11.2026
Для `vietnam-cambodia-2027` отдельно проверены права на 52 приватных файла/папки из owner-only escrow: metadata показывает только владельца. Все **10 выбранных кадров** и **10 уже изготовленных MP4 A2E** получены из закрытого Google Drive и декодированы без ошибок; по всем кадрам совпали заявленные размеры байтов, видео — H264, 1080×1920, около 5,06 с. Точные SHA-256 хранятся **только** в закрытой проверке `Simba_Vietnam_Cambodia_2027_Private_Media_QA_2026-11-17`. Старые `A2E_NOT_STARTED` и `CLIPS_NOT_GENERATED` были противоречивыми статусами и исправлены. **Нельзя повторно оплачивать A2E** на основе старого статуса. Визуальное соответствие сцен, утвержденная озвучка, лицензия музыки, тайминги и финальный мастер по-прежнему не согласованы; ни один editor/publish gate не повышен.

### Безопасность приватных материалов — 17.11.2026
Публичные проектные JSON для Bavaria, Prague и Vietnam/Cambodia больше не содержат прямых owner-only Google Drive URL/file ID. Оригинальные JSON и 62 URL сохранены в проверенном owner-only архиве `Simba_Private_Media_Locator_Escrow_2026-11-17` внутри `Simba Media Archive` (не помещать ссылку в GitHub). `PRIVATE_MEDIA_ESCROW_20261117` в публичном реестре означает **требуется авторизованная сверка приватных ассетов**, а не наличие доступного клипа. Текущие stage/approval сохранены как исторические решения, не подтверждение внешних байтов. Публикация и повторная оплата не разрешаются этим переносом. Предыдущие коммиты Git остаются потенциально доступными.
