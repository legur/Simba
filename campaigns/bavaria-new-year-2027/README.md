# Бавария. Новый год

Точка продолжения: [project.json](project.json).

Основные факты, сценарий и последовательность результатов: [каноническая производственная сессия](../../SIMBA%20KNOWLEDGE%20BASE/03_CONTENT_LIBRARY/2026-11-08__SELLING__BAVARIA-NEW-YEAR__APPROVED.md).

В записи связаны шесть существующих A2E-клипов, архив семи WAV, озвученный черновик, SRT, обложка и отчет QA. Рабочая версия и утвержденный финал учитываются раздельно. Последняя правка Лео по второй модели и субтитрам требует сверки перед продолжением.

```bash
python3 integrations/materials/catalog.py resume Бавария
python3 integrations/materials/catalog.py reuse Бавария
```

Сначала прочитать актуальную сессию и текущую правку; не повторять готовые платные стадии по старому input ZIP.
