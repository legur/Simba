# MVP acceptance criteria

- [ ] Из трёх тестовых изображений создаётся воспроизводимый вертикальный MP4 1080×1920.
- [ ] Видео содержит выбранный из пяти хуков и финальный CTA.
- [ ] Поддерживаются кириллица и иврит с корректным RTL.
- [ ] Факты предложения проверяются по свежему источнику, конфликт блокирует выпуск.
- [ ] Видео проходит ffprobe-проверку кодека, разрешения и длительности.
- [ ] Повторный рендер не повреждает исходники.
- [ ] У пользователя есть ручное утверждение до экспорта.
- [ ] Никаких публикаций или изменений Wix без подтверждения.
- [ ] Тесты и результаты команд документированы.
